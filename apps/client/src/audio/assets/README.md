# Записи, готовые к употреблению

Сюда ссылается `../assets.ts` поимённым импортом. Всё, что здесь лежит,
уже обрезано до нужной длины; громкость, затухание и сглаживание краёв
накладывает загрузчик после декодирования — три его обязанности описаны
во вводном комментарии `assets.ts`.

Необработанное живёт в `source/` и в сборку не попадает.

## Происхождение записей ядерной ракеты

Обе принёс владелец продукта 28.08.2026 в ответ на задачу 0025;
лицензию он взял на себя. Исходники лежали в `source/` и удалены после
нарезки, как того требует `source/README.md`; в истории они остаются
коммитами `242a1aa7` и `bc987b90`.

Резалось **по границам кадров MP3, без перекодирования**: из исходника
копируется целое число кадров подряд, и байты внутри взятого отрезка
совпадают с исходником побайтно. Перекодирование испортило бы ровно то,
ради чего запись и берут.

### `nuke-launch.mp3` — пуск

|                      |                                                               |
| -------------------- | ------------------------------------------------------------- |
| Исходник             | `rocket-flight.mp3`, 800 226 байт, sha256 `315df26b…40da910e` |
| Взято                | байты 16 425 … 49 025, 78 кадров, 2,038 с                     |
| Результат            | 32 601 байт, sha256 `a24a7a82…c20b51e40`                      |
| Дальше в `assets.ts` | `take: 1.6`, `fadeFrom: 1.15`                                 |

Имя исходника обманчиво: «flight» — это пуск, а не полёт. В записи
сорок девять секунд, из них первые две — тишина, розжиг и выход
двигателя на режим, а дальше ровный удаляющийся гул до самого конца.
Событие в игре — старт, поэтому взято начало.

### `nuke-fall.mp3` — свист подлёта

|                      |                                                               |
| -------------------- | ------------------------------------------------------------- |
| Исходник             | `rocket-sound-2.mp3`, 89 277 байт, sha256 `6b866d89…e8d13ef3` |
| Взято                | байты 14 336 … 51 950, 90 кадров, 2,351 с                     |
| Результат            | 37 615 байт, sha256 `7bb0bfb3…1c57e2824`                      |
| Дальше в `assets.ts` | `take: 2`, `fadeFrom: 1.55`                                   |

Взято начало: в нём весь свист. Высота за первые две секунды падает
впятеро — переходов через ноль с 5 100 до 2 400 в секунду, — а дальше
остаётся хвост ниже пятой доли пика, который всё равно ушёл бы
в затухание.

Длина неслучайна: две секунды — это `NUKE_FALL_TICKS`, то есть ровно
столько, сколько свист и звучит. Он приходит **к попаданию**, а не
тянется от пуска все три секунды `NUKE_DELAY_TICKS`.

### Как это проверить заново

Числа выше сняты разбором заголовков MP3 и декодированием записи
настоящим декодером браузера. Своего декодера в проекте нет, и заводить
его ради разовой нарезки незачем: инструмент был временным и в продукт
не поехал.
