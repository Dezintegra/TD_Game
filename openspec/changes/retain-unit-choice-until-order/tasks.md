## Правила доставки каждого пункта

Каждый пункт — самостоятельный коммит и немедленная отправка `git -C <дерево> push`. Добавлять явным списком только рабочие пути пункта и обязательную отметку его выполнения в `openspec/changes/retain-unit-choice-until-order/tasks.md`. До коммита проверить имена и содержание через `git -C <дерево> diff --cached --name-only` и `git -C <дерево> diff --cached`; после — через `git -C <дерево> show --stat HEAD` и `git -C <дерево> show HEAD`. Допуск своего tasks.md не разрешает несвязанные правки. Для шага 1 допустимы только перечисленные там файлы и tasks.md; для шага 2 — production.match.test.ts и tasks.md. Временные пробы и логи в коммит не включать.

Формы команд сверены с `supervisor/config/stage-settings.json`: Git вызывается через `-C`, узкие проверки через разрешённые `npx vitest` и `npx eslint`. Полные проверки, ожидание CI и прогон арены не являются пунктами исполнителя. Результаты CI обрабатывает конвейер; заявку на арену после вливания передаёт отчёт design.
