## ADDED Requirements

### Requirement: Файл тела PR убирается только в пределах собственной задачи

Скилл имплементации SHALL рядом с командой открытия чернового PR через `gh pr create --body-file` называть место файла тела внутри назначенного дерева и порядок обращения с ним после подтверждённого успеха команды. Путь в пояснении и доводе команды SHALL совпадать; номер созданного PR SHALL сохраняться для отчёта до уборки.

Для собственного неигнорируемого неотслеживаемого файла скилл SHALL предписывать проверку принадлежности текущей задаче по записи создания, отсутствия чужих правок, статуса Git и разрешённого абсолютного пути обычного отдельного файла внутри назначенного дерева. Неизвестный, отслеживаемый, чужой файл, каталог или путь за пределы дерева удалять по этому порядку MUST NOT.

Только после этих проверок скилл SHALL предписывать форму `git -C <дерево> clean -f -- <точный относительный путь>`, удаляющую один проверенный файл. Шаблоны, pathspec magic, очистку всего дерева, переход через ссылки наружу и расширяющие область ключи скилл предписывать MUST NOT. После операции скилл SHALL требовать проверки статуса: целевой файл исчез, чужие изменения сохранены. Ошибку проверки или удаления считать успешной уборкой MUST NOT.

Для игнорируемого файла в `.matchlog/` скилл SHALL объяснять, что он не загрязняет обычный `git status` и не удаляется указанной формой clean. Ради него скилл MUST NOT требовать широкую очистку, ослабление разрешений или повтор отказанного Remove-Item.

#### Scenario: Собственное неигнорируемое тело после успешного открытия

- **WHEN** черновой PR успешно создан, файл тела не отслеживается и не игнорируется, принадлежность текущей задаче и путь внутри её дерева подтверждены, чужих правок в нём нет
- **THEN** инструкция сохраняет номер PR, предписывает точечный clean только этого файла и последующий статус; целевая строка исчезает, остальные изменения сохраняются

#### Scenario: Тело лежит в игнорируемом matchlog

- **WHEN** тело созданного PR лежит в игнорируемом `.matchlog/`
- **THEN** инструкция допускает оставить файл, объясняет его отсутствие в обычном статусе и неприменимость указанной формы удаления; расширять очистку не требует

#### Scenario: Не подтверждены владение или допустимый путь

- **WHEN** происхождение файла неизвестно, в нём есть чужие правки, он отслеживается, является каталогом либо его разрешённый путь выходит из назначенного дерева
- **THEN** инструкция запрещает удалять его по порядку уборки тела PR и требует назвать препятствие вместо очистки неизвестных файлов

#### Scenario: Создание PR не подтверждено

- **WHEN** gh pr create завершился ошибкой или результат создания неизвестен
- **THEN** инструкция не запускает уборку после успеха и сохраняет тело для восстановления операции

#### Scenario: Уборка или проверка статуса не удалась

- **WHEN** точечное удаление отказано, проверка статуса завершилась ошибкой либо целевой файл остался
- **THEN** инструкция требует сообщить проблему, не объявлять уборку успешной и не повторять отказанный Remove-Item, не расширять clean и не ослаблять разрешения

#### Scenario: Размещение тела PR уточнено соседней задачей

- **WHEN** действующий шаг открытия PR уже задаёт место тела внутри назначенного дерева
- **THEN** инструкция уборки использует тот же путь, а выбор между точечным удалением и допустимым сохранением определяется фактическим статусом ignore
