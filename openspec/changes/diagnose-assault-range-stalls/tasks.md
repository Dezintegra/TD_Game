## Правила каждого коммита

Каждый checkbox — один самостоятельный коммит, сразу отправленный. Все перечисленные пути каждого пункта допускают также обязательную отметку только этого выполненного пункта в `openspec/changes/diagnose-assault-range-stalls/tasks.md`. Нельзя добавлять посторонние изменения внутри разрешённых файлов или отмечать будущие пункты. Добавлять фактически изменённые файлы явным перечнем, не весь репозиторий.

Перед коммитом выполнить `git -C <дерево> diff --cached --name-only` и `git -C <дерево> diff --cached`, проверить имена и содержание; после коммита — `git -C <дерево> show --stat --oneline HEAD` и `git -C <дерево> show --format=fuller HEAD`. Каждый вызов — отдельная команда. Временные `.matchlog/` и скачанные базы/сырые логи не включать в индекс или коммит. Новые протоколы/схемы сверять узкими тестами и типами CI, не запускать полный verify из дерева.

Арену и матчевые тесты локально не запускать; ожидание CI, запуск заявки и интерпретация результатов не являются пунктами implement. Супервизор проверит CI и направит правки по его исходу. Изготовление прибора заканчивается после доставки всех пунктов; причинный вывод по полным матчам принадлежит последующему прогону. Изменение основных спецификаций/архивация не входят в задачи этого этапа.
