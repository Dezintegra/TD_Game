## ADDED Requirements

### Requirement: Команда, выписанная в список задач, дана формой, покрытой правилами разрешений

Команда, которую проработка выписывает в `tasks.md`, SHALL быть дана
в той же форме, в какой её дают правила этапов: форме, покрытой
правилами разрешений `supervisor/config/stage-settings.json`. Для `git`
эта форма — `git -C <дерево> …`.

Выписывать команду `git` голой формой — без `git -C <дерево>` — проработка
MUST NOT. Правила разрешений сверяются с приставкой команды, и покрыта
голая приставка не у всякой подкоманды: `git merge` не покрыт ни одним
правилом, тогда как `git -C:*` покрывает любую подкоманду разом. Заменить
это заходом в каталог отдельным звеном цепочки нельзя — склеивать команды
исполнителю запрещено тем же сводом правил.

Правила проработки SHALL называть эту форму прямо и SHALL называть обе
причины: непокрытость голой приставки и запрет склейки. Умолчание здесь
не нейтрально: сессия, не знающая правила, пишет команду так, как её
пишут памятки проекта, — голой, — и передаёт исполняющему этапу шаг,
которого тот выполнить не может. Отказ проверки разрешений в автономной
сессии возвращается ответом на вызов, а не вопросом человеку, поэтому
такой шаг оборачивается либо самодельной заменой, либо мнимо выполненной
работой, и в отчёте выглядит успехом.

Правило живёт одной фразой в длинном файле правил, поэтому его наличие
SHALL стеречься проверкой конвейера, называющей провинившийся файл.

#### Scenario: Проработка выписывает в список задач команду git

- **WHEN** сессия проработки пишет в `tasks.md` шаг, исполняемый
  командой `git`
- **THEN** команда выписана формой `git -C <дерево> …`, а не голой

#### Scenario: Правила проработки прочитаны на предмет формы команд

- **WHEN** файл правил этапа проработки проверяется на указание о форме
  команд списка задач
- **THEN** в нём названа форма `git -C <дерево>` и названы обе причины —
  непокрытость голой приставки и запрет склеивать команды

#### Scenario: Указание о форме вычищено из правил проработки

- **WHEN** правка файла правил проработки убирает из него указание
  о форме команд
- **THEN** проверка конвейера падает и называет этот файл
