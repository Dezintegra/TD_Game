## Правила каждого коммита

Каждый отмеченный пункт — отдельный коммит, сразу отправляемый командой `git -C <дерево> push`. Явно добавить только перечисленные для пункта рабочие пути и `openspec/changes/require-local-run-source/tasks.md` с отметкой выполнения именно этого пункта. Перед коммитом проверить имена и содержание через `git -C <дерево> diff --cached --name-only` и `git -C <дерево> diff --cached`; после — `git -C <дерево> show --stat --oneline HEAD` и `git -C <дерево> show --format=fuller HEAD`. Допуск tasks.md не разрешает несвязанные правки в нём или других перечисленных файлах.

Команды Vitest покрыты PowerShell(npx vitest:*) из stage-settings.json; обязателен `--root supervisor`. Узкие проверки форматирования и линта — только по собственным изменённым файлам. Полный verify, ожидание CI, арена и локальный perf не являются пунктами этого плана. CI опрашивает супервизор после открытия PR.
