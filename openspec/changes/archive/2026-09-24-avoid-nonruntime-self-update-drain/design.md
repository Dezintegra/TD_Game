## Context

Сейчас `judgeSelfUpdate` сравнивает хеш всего дерева `supervisor/` с хешем на момент запуска. Любое различие включает ожидание тихого момента. PR #304 изменил только `README.md` и `configure-watchdog-power.ps1` внутри этого дерева, поэтому живой супервизор оставил свободный слот незанятым на время длительного этапа 0383. При этом правила этапов передаются новому дочернему процессу по пути файла, а не кэшируются в супервизоре.

## Goals / Non-Goals

**Goals:** после коммитного изменения файлов, которые текущий процесс не загружает, сохранить приём новых этапов, дальнейшую проверку удалённой ветки и безопасный перезапуск при следующем изменении исполняемого кода.

**Non-Goals:** немедленное применение изменений модулей, конфигурации или неизвестных файлов; учёт незакоммиченных правок; прерывание живых этапов.

## Decisions

1. Git-адаптер получает разницу двух хешей деревьев `supervisor/` через `git diff --name-only -z --no-renames --no-ext-diff`. Пути относительны корню этого дерева; NUL сохраняет имена с пробелами и переводами строк. `--no-renames` показывает и удалённый исполняемый путь, и добавленный документ: такое перемещение не может быть ошибочно признано безопасным.
2. Белый список ограничен `README.md`, `permission-diagnostics.md`, файлами `skills/*.md`, тестами `*.test.mjs` и точным `configure-watchdog-power.ps1`. Файл правил этапа читается новой дочерней сессией при её запуске. Неизвестные пути, конфигурация, исполняемые модули и скрипты запуска требуют рестарта. В отличие от широкого правила по расширению `.md` это не признаёт будущий неизвестный Markdown-файл безопасным без проверки его роли.
3. Разницу проверяем только если хешы не совпадают. Пустая разница при разных хешах или ошибка Git считается неопределённостью: прежнее ожидание и рестарт. Если различия безопасны, выполняется существующая проверка удалённой ветки и ускоряющее подтягивание. После подтягивания разница сравнивается снова с исходным хешем запуска; накопившееся изменение кода не теряется.

## Risks / Trade-offs

- [Динамически загружаемый документ позже начнут читать как конфигурацию] → белый список точных ролей, проверка при добавлении такого чтения и перезапуск для всех неизвестных путей.
- [Ошибка чтения разницы или неожиданная разница] → консервативное прежнее поведение с перезапуском.
- [Дополнительный Git-запрос] → он выполняется только после изменения хеша дерева, а не в каждом неизменном обороте.

## Migration Plan

После зелёного CI слить изменение; действующий процесс применит его после своего обычного безопасного рестарта. Откат — возврат коммита, после которого прежнее правило снова вступит в силу. На клиентскую отзывчивость и сетевой трафик игры влияние отсутствует.
