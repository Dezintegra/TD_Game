# build-towers-in-force

Противник ставит башни группой, а не по одной за решение.

Замер на двадцати матчах арены: семнадцать башен построено за матч,
на карте одновременно держится **0,56**. Место находится всегда, деньги
есть, ядро команду принимает — и всё равно башен нет. Теряются они ровно
с той скоростью, с какой ставятся: одиночную башню сносит толпа.

Правило «одна покупка за решение» означает, что вторая башня появится
через полсекунды, третья — через секунду, и всё это время первая стоит
одна. При возведении в шесть секунд группа из трёх собирается полторы
минуты.

**Предел группы — не счётчик.** Границы две, обе уже есть в коде: казна
за вычетом заказанного и `freshCoverage`, обращающаяся в ноль, когда
накрывать нечего. Радиус строительства и дальность башни равны пяти
клеткам, поэтому покрытие в окрестности генерала насыщается само.

**Заодно чинится ядерный запас.** Поздняя фаза держит под удар 37 500
единиц, и цена любой покупки складывается с ними: 1014 решений подряд
без единой покупки при энергии на шесть башен. Ударов за те же двадцать
матчей — ноль. Запас начинает держаться только тогда, когда доход
позволяет его набрать за горизонт накопления.

**Соседи.** `fortify-approaches` отвечает на вопрос **где** ставить
(взаимное прикрытие, узкие места коридора); здесь — **сколько за раз**.
Изменения независимы и складываются: группа даёт башням оказаться рядом
уже сейчас, мерка места сделает это осознанным выбором.

**Порядок.** Опирается на `sealsApproach` из `add-structure-demolition`
и на защитное кольцо из `protect-base-surroundings`: обе проверки группа
выполняет для каждой постройки, а не один раз.
