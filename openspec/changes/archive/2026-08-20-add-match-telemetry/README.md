# add-match-telemetry

Арена: безголовые матчи компьютер-против-компьютера, запись матчей
и разбор логов через SQLite.

Поведение противника оценивается глазами: «топчется», «не наступает».
Наблюдения верные, но их нельзя ни измерить, ни воспроизвести, а причину
не видно — мир показывает, что случилось, и не показывает, чего
противник хотел. Ядро и противник детерминированы, поэтому матч
восстанавливается из seed и команд; арена этим и пользуется.

Устройство: браузер пишет **тонкую** запись (входы, ≈50 КБ), арена
прогоняет её заново и порождает **толстый** лог (решения, все оценённые
рубежи, отказы, сэмплы), `ingest` собирает SQLite, разбор идёт запросами.

**Порядок.** Третье из трёх связанных изменений, делается последним:

- `report-rejected-commands` — иначе лог команд систематически врёт;
- `extract-ai-package` — иначе арена не вправе импортировать противника,
  и нечем задать профили сторон.


**Состояние:** реализовано, все задачи закрыты, `pnpm verify` зелёный.
