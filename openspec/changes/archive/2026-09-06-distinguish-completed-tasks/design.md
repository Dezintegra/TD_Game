## Context

Сейчас `closed` означает любой конец. Уборка допускает отсутствие записи дерева; это не доказательство выполнения. Декомпозиция возвращает `split`, снятие предмета — `moot`, успешный этап — `done`.

## Goals / Non-Goals

Разделить выполненную постановку и прекращение работы. Не менять игровые системы и не переклассифицировать историю автоматически.

## Decisions

- Ввести `completed` как отдельное терминальное состояние и колонку, сохранив `closed` для административного закрытия. Метка вместо состояния не подходит: статус доски должен быть однозначным.
- Успешное толкование прогона заканчивается `completed`. Разбор заметки без заявок завершается `completed`; разбор с передачей работы новым карточкам — `closed`.
- Уборка задачи с PR заканчивается `completed` только после проверки вливания, включая случай отсутствующего дерева. Уборка без PR заканчивается `closed`: это существующий маршрут снятия предмета. Признак не хранится отдельным дублирующим полем.
- Зависимости и автоматическое возвращение после исправления требуют `completed`. `closed` без частей не подтверждает выполнение. Новая логика main сохраняется: закрытый родитель с `splitInto` делегирует проверку всем частям; каждый конечный потомок должен быть `completed`. Проверка конкретного merged-pr сохраняется.
- Схемы, терминальность, отображение, запрет дописывания фактов и инструкции получают новый статус.

## Risks / Trade-offs

Старые закрытые предшественники остановят зависимые задачи → не угадывать результат, переносить только после проверки истории и артефактов.
Старый супервизор не знает колонку → сначала поставить код на станции и перезапустить между этапами; затем переносить карточки. Добавление пустой колонки безопасно.
Переход мышью в `completed` не заменяет проверку постановки → штатные маршруты и проверки этапов сохраняются.

## Migration Plan

Создать колонку через идемпотентный board-setup. Код доставить PR после CI; обновлять работающий супервизор штатно, не перехватывая задачи. Не выполнять массового переноса старых карточек без доказательств. Откат требует остановки выдачи сессий и согласованного возврата карточек из новой колонки перед старым читателем.
