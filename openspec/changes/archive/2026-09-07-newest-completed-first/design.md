## Context

`saveTask` меняет колонку и описание одним запросом. Позиция задаётся только для блокирующих задач, остальные сохраняют числовое место из прежней очереди. Снимок доски читается один раз за цикл.

## Goals / Non-Goals

**Goals:** новый переход в `completed` размещает карточку сверху; повторное сохранение выполненной карточки сохраняет порядок.

**Non-Goals:** менять рабочие очереди, критерии завершения или автоматически пересортировывать исторические карточки каждым циклом.

## Decisions

- Добавлять `pos: top` в существующий PUT при смене колонки на `completed`. Это не добавляет запросов и сохраняет неделимость перемещения и отметок.
- Определять текущую колонку по снимку и подтверждённым сохранениям в этом экземпляре адаптера. Журнал `entry.from` может повторяться после неудачной публикации комментария; только на него полагаться нельзя. Отдельная карта подтверждённых колонок сохраняет исходный снимок неизменным.
- Уже выполненная карточка не получает `pos`, даже если повторный отчёт содержит старый `from` или флаг `blocking`. Для остальных колонок действующее правило блокирующих задач сохраняется.
- Текущую колонку сортировать отдельной разовой операцией по истории фактического завершения. Подтверждено 47 видимых карточек; 0166 использует закрытие владельцем 03.09, повторные уборки остальных — первую запись завершения. Меняется только `pos`, архивные карточки остаются нетронутыми.

## Risks / Trade-offs

- Успешное перемещение с последующим отказом комментария → запомнить подтверждённую колонку до комментария; повтор не поднимает старый результат.
- Отказ самого PUT → не запоминать переход; повтор снова запрашивает верхнюю позицию.
- Изменение доски вне супервизора после снимка → сохраняется существующая модель одного снимка на цикл; постоянная пересортировка и дополнительный опрос не вводятся.

## Migration Plan

Существующий порядок уже исправлен с резервным снимком и проверкой после записи. Код вступает в действие после вливания и штатного обновления супервизора. Откат кода возвращает прежнее правило будущих переходов, текущий порядок сохраняется.
