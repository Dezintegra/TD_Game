## Context

У запуска 0242 отсутствует stdout и завершение turn. В v2 ledger запуск завершён обработчиком сирот без observations. sessionEvidence отбрасывает незавершённый turn, а recoveryPlan берёт только legacy-unknown.

## Goals / Non-Goals

Автоматически принять доказанный минимум и вернуть остановленную задачу обычному планировщику. Не считать минимум полным расходом и не восстанавливать отчёт этапа по токенам.

## Decisions

1. Опциональный режим allowIncomplete в разборщике разрешает только последний незавершённый turn при непрерывных современных records. Строгие потребители и legacy CLI остаются прежними. Проверяются timestamp запуска, идентичность и все накопители.
2. Отдельная функция принятия доказательства меняет только запуск с допустимыми причинами потери вывода. При неполном журнале хранит acceptance с политикой, снимком, временем и хешем доказательства; причины сохраняются. taskTokenStatus.complete остаётся false; отдельный acceptedIncomplete разрешает только подтверждённые причины. Ошибки хранения и новые неизвестности блокируют.
3. Восстановление вызывается sweep для известных остановленных сессий без живого дескриптора/отчёта. Runtime получает точный cwd из реестра. При перезапуске берёт уже удержанные задачи. Атомарная запись ledger предшествует допуску; повтор ничего не меняет.
4. Неполную сессию не возобновлять: новый запуск начинается с нуля в новой сессии, старый минимум остаётся в сумме задачи. В журнале возврата и результата назвать неполноту.

## Risks / Trade-offs

Неизвестный хвост может увеличить фактический общий расход сверх лимита. Это осознанная политика продолжения по подтверждённому минимуму, а не гарантия полного бюджета. Автоматических дополнительных вызовов модели для восстановления нет. Повреждённый/отсутствующий журнал по-прежнему требует вмешательства.

## Migration Plan

Установить изменение через PR и штатное самообновление. Следующий sweep восстанавливает 0242 и похожие остановленные задачи. При откате исходные reasons остаются и старый код вновь блокирует неполный учёт. Ledger не переписывается оператором.
