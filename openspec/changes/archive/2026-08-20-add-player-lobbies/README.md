# add-player-lobbies

Игра обретает игроков: имя в куки, список лобби, вход, готовность
и общий старт матча.

Сейчас клиент открывается сразу в матче против компьютера. Игрока как
сущности не существует: у него нет имени, его нельзя ни с кем свести,
и второй человек, открывший ту же страницу, попадает в свою отдельную
партию. Изменение добавляет мета-слой поверх матча — представление,
список лобби, готовность обеих сторон и выдачу общего seed со сторонами.

**Порядок.** Первое изменение сетевой ветки. Синхронизация самого матча
(передача команд, предсказание, откат) — отдельное следующее изменение,
и это изменение готовит для неё почву: сервер уже назначает матчу
идентификатор, seed и стороны.

**Состояние:** реализовано, все задачи закрыты. `pnpm verify` зелёный
(541 юнит-тест), `pnpm e2e` зелёный (16 тестов, включая сценарий
на двух браузерах). `packages/sim` не тронут, эталон детерминизма
зелёный без правки числа.
