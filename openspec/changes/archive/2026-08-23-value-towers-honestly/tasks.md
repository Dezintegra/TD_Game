# Задачи

Сначала мерка, потом очередь. Порядок важен: снять запрет обгонять
накопление, не починив оценку башни, значит пустить вперёд юнита —
его-то прибавка считается честно и без того.

## 1. Базовая линия

- [x] 1.1 Снять базовую линию на seed 3000–3019: доля решений, не дошедших
      до попытки построить, и кто обрывает очередь.
      *Проверка:* 62,1% не дошли; обрывают 10 554 «коплю» на улучшении
      и 3272 на юните; при постройке не первой в порядке — 100%.

      балансе.
      *Проверка:* башня 3,75 без роста и 4,59 с ростом, средний юнит 2,43,
      улучшение атаки при десяти штурмовиках 0,98.

## 2. Мерка башни

- [x] 2.1 `towerGain` в `posture.ts`: урон в тик × горизонт × курс,
      умноженное на долю накрытого пути.
      *Проверка:* тесты «башня, не накрывающая путь, не стоит ничего»,
      «прибавка растёт вместе с покрытием», «покрытие сверх круга
      дальности прибавки не добавляет».
- [x] 2.2 Средний множитель роста за убийства, с потолком из баланса.
      *Проверка:* при нынешнем балансе ×1,225; без убийств ×1;
      при огромном уроне упирается в тысячекратный потолок.
- [x] 2.3 `spendEfficiency` берёт `towerGain` вместо `verdict.gain`,
      покрытие считается по тому же месту, куда башня и встанет.
      *Проверка:* `pnpm typecheck` зелёный; аргумент `verdict` из
      `spendEfficiency` ушёл совсем — связь с рубежом разорвана.
- [x] 2.4 `scoreFrontier` не изменился ни строкой.
      *Проверка:* `git diff` по функции пуст; `posture.test.ts` зелёный.

## 3. Очередь

- [x] 3.1 Накопление заводит порог выгоды; дальше по очереди проходят
      только траты, дающие строго больше.
      *Проверка:* тест «копя на одно, противник покупает другое, если оно
      выгоднее»; в замере таких решений 1935.
- [x] 3.2 Неизвестная прибавка считается непревосходимой.
      *Проверка:* тест «накопление на несравнимое не пускает вперёд
      никого» — в ранней фазе, где интересна одна экономика.
- [x] 3.3 Порог берётся наибольший, если копится сразу на несколько.
      *Проверка:* `Math.max` в накоплении порога; уступать надо лучшему
      из отложенного.
- [x] 3.4 Счётчик терпения растёт только в решениях, где не куплено ничего.
      *Проверка:* тест «купив, противник не считается копившим».
- [x] 3.5 Причина `saving-for-better` в наблюдателе.
      *Проверка:* тест «уступившая очередь трата различима в разборе»;
      в базе арены причина видна без правки схемы.
