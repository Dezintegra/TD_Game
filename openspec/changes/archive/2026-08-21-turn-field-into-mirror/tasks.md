# Задачи

Разделы независимы и дают связную игру каждый по отдельности: после
первого выстрелы различаются в состоянии мира, но выглядят по-прежнему;
после второго поле становится зеркалом; после третьего выстрелы
получают облик. Останавливаться можно после любого.

## 1. Вид оружия доезжает до клиента

- [x] 1.1 Завести `ShotWeapon` (трассер, луч, разряд) в
      `packages/shared/src/balance.ts` и две таблицы соответствия:
      по типу юнита и по виду постройки. Оружие генерала — трассер.
      _Проверка:_ у каждого типа юнита и каждой стреляющей постройки
      есть запись — тест по перечислениям, а не по списку руками.
- [x] 1.2 Заменить `SHOT_LIFETIME_TICKS` таблицей по видам оружия,
      оставив прежнее число сроком трассера. Срок луча — вдвое больше.
      _Проверка:_ тест на соотношение сроков; прежняя константа
      не осталась висеть неиспользованной.
- [x] 1.3 Поле `weapon` в `ShotState` (`packages/sim/src/world.ts`)
      с объяснением, почему величина рендера живёт в ядре, — рядом
      с уже стоящим там объяснением про `lethal`.
      _Проверка:_ типы собираются, поле обязательное.
- [x] 1.4 `recordShot` в `packages/sim/src/working.ts` принимает оружие
      и берёт из него срок жизни. Третьего аргумента со сроком не заводить:
      два источника одной величины разъедутся.
      _Проверка:_ след луча живёт вдвое дольше следа трассера — тест.
- [x] 1.5 Три точки выстрела в `packages/sim/src/combat.ts` передают
      оружие стрелка: юнит — по типу, постройка — по виду, генерал —
      трассером.
      _Проверка:_ три теста, по одному на стрелка.
- [x] 1.6 Убедиться, что контрольная сумма и эталон детерминизма
      не сдвинулись. Если сдвинулись — значит, задето правило,
      и это ошибка, а не повод переписать эталон.
      _Проверка:_ `determinism.golden.test.ts` и `profile.golden.test.ts`
      зелёные без правки чисел.

## 2. Поле становится зеркалом

- [x] 2.1 Добавить цвет поверхности поля в `ModelColors` и `EntityColors`,
      читать его из `--td-bg-page` в `scene.ts` — там же, где читаются
      остальные токены.
      _Проверка:_ литерала цвета в отрисовке не появилось.
- [x] 2.2 Зеркальный силуэт в `apps/client/src/game/models.ts`. Строить
      из деталей заново, опрокидывая **высоту**, а не экранную `y`:
      в этой проекции `y` несёт и высоту, и положение на плоскости,
      и опрокинутое отражение уехало бы вбок. Цвета подмешать к цвету
      поверхности, окантовку не переносить.
      _Проверка:_ тесты — отражение лежит под машиной и не смещено
      по горизонтали, сплюснуто по высоте, приглушено, `outline` пуст.
- [x] 2.3 Кеш отражений рядом с кешем силуэтов, по тем же ключам,
      с тем же сбросом при смене палитры.
      _Проверка:_ повторный запрос возвращает ту же запись; смена
      палитры её меняет.
- [x] 2.4 Парение в `apps/client/src/game/entities.ts`: постоянный подъём
      плюс покачивание с фазой от номера юнита и временем от тика.
      Полоса здоровья поднимается вместе с машиной, иначе повиснет
      отдельно от неё.
      _Проверка:_ тест — два юнита с разными номерами в один тик подняты
      на разную высоту; тот же юнит в разные тики — тоже.
- [x] 2.5 Отрисовка отражений юнитов и генерала. Отражение ставится
      в очередь той же глубины, что тело, но раньше него; тень генерала
      остаётся.
      _Проверка:_ тест — тело и его отражение попадают в одну полосу
      глубины, отражение рисуется первым.
- [x] 2.6 Подъём генерала оставить больше подъёма юнита с запасом.
      _Проверка:_ тест сравнивает две величины, а не полагается на глаз.

## 3. Выстрелы получают облик

- [x] 3.1 Разложить `drawShots` по видам оружия, ветку трассера оставить
      слово в слово прежней.
      _Проверка:_ след штурмовика даёт ту же геометрию, что и до правки.
- [x] 3.2 Луч: широкий приглушённый ореол, яркое тонкое ядро, зеркальная
      копия в поверхности, затухание по остатку срока жизни.
      _Проверка:_ тесты — луч толще трассера, ниже плоскости земли есть
      его копия.
- [x] 3.3 Разряд: ломаная в семь изломов с одной-двумя ветвями,
      поперечное смещение гаснет к концам. Генератор засевается хешем
      от координат выстрела и номера тика.
      _Проверка:_ тесты — первая точка у стрелка, последняя в цели;
      в одном тике форма повторяется, в соседнем различается.
- [x] 3.4 Поднять начало следа на высоту парения, чтобы выстрел выходил
      из машины, а не из-под неё.
      _Проверка:_ величина выражена через подъём юнита, а не числом.
