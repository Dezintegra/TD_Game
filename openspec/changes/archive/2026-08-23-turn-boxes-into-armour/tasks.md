# Задачи

Разделы независимы и дают связную игру каждый по отдельности: после
первого примитив умеет скос, но им никто не пользуется и картинка
не меняется; после второго скос доезжает до модели и до отражения;
после третьего машины выглядят бронёй. Останавливаться можно после
любого.

## 1. Тело учится скосу

- [x] 1.1 Завести `VIEW_DIRECTION_3D` в `apps/client/src/game/iso.ts`
      рядом с нынешним плоским, с выводом из решения `x_s = 0, y_s = 0`
      в комментарии.
      _Проверка:_ тест на то, что горизонтальная часть нового вектора
      сонаправлена нынешнему `VIEW_DIRECTION` (векторное произведение
      равно нулю, скалярное положительно), и что вектор единичный.
- [x] 1.2 Дать `faceLight` третий необязательный аргумент — вертикальную
      составляющую нормали, — и вывести `LIGHT_Z` из `AMBIENT`,
      а не задать литералом. Объяснить в комментарии, почему
      `LIGHT_Z = 1 − AMBIENT` — это не подгонка, а требование
      совпадения с `FACE_LIGHT.top`.
      _Проверка:_ `faceLight(0, 0, 1)` равен `FACE_LIGHT.top`;
      `faceLight(1, 0)` и `faceLight(1, 0, 0)` равны `FACE_LIGHT.right`;
      значения `FACE_LIGHT` не изменились ни на знак.
- [x] 1.3 Дать `solidFaces` четвёртый необязательный аргумент — верхнее
      основание. Нормаль считать векторным произведением ребра
      на подъём, видимость — по `VIEW_DIRECTION_3D`.
      Три первых аргумента и поле `light` не трогать: их зовёт
      соседнее изменение.
      _Проверка:_ вызов с тремя аргументами даёт результат, совпадающий
      с прежним, — сравнение с эталоном в тесте, а не на глаз;
      у тела со скосом число граней то же, а освещённость боковой
      лежит между отвесной и верхней.
- [x] 1.4 Проверить, что `prismFaces` и путь скал не задеты вовсе.
      _Проверка:_ существующие тесты `prism.test.ts` зелёные без правок.

## 2. Скос доезжает до модели

- [x] 2.1 Завести у детали (`Part` в `models.ts`) необязательное поле
      скоса: стягивание к центру и сдвиг вперёд и вбок. Вычисление
      верхнего основания вынести в отдельную функцию с ограничением
      стягивания нулём.
      _Проверка:_ стягивание больше радиуса основания даёт вырожденное
      верхнее основание в центре, но не вывернутое.
- [x] 2.2 Научить `buildSilhouette` передавать верхнее основание
      в `solidFaces`. Деталь без скоса обязана давать прежние грани.
      _Проверка:_ силуэт при пустой таблице скосов совпадает с прежним
      многоугольник в многоугольник.
- [x] 2.3 Починить отражение: у опрокинутой детали верх становится низом.
      Приводить деталь к явным основаниям перед опрокидыванием
      и менять их местами. Обратного стягивания не изобретать —
      его не существует.
      _Проверка:_ отражение скошенного тела сужается книзу, а не кверху;
      отражение отвесного тела не изменилось.
