## 1. Примитив объёмного тела

- [x] 1.1 Ввести перевод высоты в экранные пиксели через параметры проекции. Проверка: `ELEVATION_PX_PER_CELL` выводится из масштаба и наклона камеры, а не задан отдельной константой.
- [x] 1.2 Реализовать функцию, отдающую четыре угла верхней грани призмы по основанию и высоте. Проверка: юнит-тест — при нулевой высоте верхняя грань совпадает с основанием, при высоте 2 смещение вдвое больше, чем при высоте 1.
- [x] 1.3 Реализовать построение двух видимых боковых граней. Проверка: юнит-тест — при нулевой высоте боковые грани не строятся.
- [x] 1.4 Реализовать затенение: множители 1.0, 0.72 и 0.48 для верхней, правой и левой грани. Проверка: юнит-тест на порядок яркости и на то, что множители одинаковы для любого базового цвета.

## 2. Порядок отрисовки

- [x] 2.1 Реализовать обход клеток по диагоналям: внешний цикл по сумме координат, внутренний по клеткам диагонали. Проверка: юнит-тест — клетки выдаются в порядке неубывания суммы координат.
- [x] 2.2 Убедиться, что обход покрывает каждую клетку ровно один раз. Проверка: юнит-тест на полноту и отсутствие повторов.
- [x] 2.3 Сгруппировать заливки внутри диагонали: одна заливка на каждый вид грани. Проверка: пять заливок на диагональ, счёт зависит от размера карты, но не от количества скал.

## 3. Скалы

- [x] 3.1 Реализовать детерминированную высоту скалы из координат клетки хешированием. Проверка: юнит-тест — повторный вызов даёт то же значение, значения лежат в объявленном диапазоне.
- [x] 3.2 Убедиться в достаточном разбросе высот. Проверка: юнит-тест — на крупном массиве встречаются клетки минимум трёх разных уровней.
- [x] 3.3 Переделать форму скалы с коробки на усечённую пирамиду со смещённой вершиной. Проверка: на экране скальный массив читается как гряда с вершинами, а не как набор кубиков.
- [x] 3.4 Чередовать острые пики и срезанные вершины, чтобы порода выглядела неоднородной. Проверка: доля усечения берётся из хеша, соседние клетки различаются.
- [x] 3.5 Добавить дизайн-токены для камня и подключить их. Проверка: литеральных цветов в коде отрисовки нет, кроме запасных значений.

## 4. База

- [x] 4.1 Описать состав командного центра данными: список частей со смещением, размером основания и высотой. Проверка: описание лежит отдельно от кода отрисовки, части сортируются по удалённости автоматически.
- [x] 4.2 Отрисовать главный корпус и две пристройки. Проверка: части различимы, пристройки ниже корпуса.
- [x] 4.3 Отрисовать мачту антенны с тарелкой наверху. Проверка: юнит-тест — антенна выше самой высокой возможной скалы.
- [x] 4.4 Отрисовать ракетную установку с наклонной направляющей. Проверка: направляющая видна рядом со зданием и не пересекает его силуэт.
- [x] 4.5 Окрасить базы цветами сторон из дизайн-токенов. Проверка: тёмный корпус с примесью цвета стороны и неоновой окантовкой; сплошная заливка неоном отвергнута — на крупном объекте она выжигает детали.

## 5. Проекция

- [x] 5.1 Заменить изометрию 45 градусов на аксонометрию с поворотом 40 и наклоном 35. Проверка: юнит-тест — оси мира несимметричны, рёбра соседних объектов не выстраиваются в одни диагонали.
- [x] 5.2 Пересчитать габариты карты через проекцию четырёх углов. Проверка: юнит-тест — границы несимметричны по горизонтали, камера упирается в край карты.
- [x] 5.3 Сохранить видимую долю карты около десятой части. Проверка: юнит-тест — при окне 1920 × 1080 видно 9,9 процента карты.
- [x] 5.4 Обновить спецификацию `isometric-view`: требование о соотношении 2:1 заменено требованием о несимметричных осях. Проверка: `openspec validate` проходит.

## 6. Интеграция и проверка

- [x] 6.1 Заменить прежнюю отрисовку контуров скал и ромба базы на объёмную. Проверка: страница открывается, на карте скальные гряды и командные центры.
- [x] 6.2 Убедиться, что земля по-прежнему рисуется только линиями. Проверка: для пустой проходимой клетки заливок нет.
- [x] 6.3 Удалить осиротевший обход рёбер границы массива и его тест. Проверка: после перехода на объёмные скалы он не используется нигде.

- [x] 6.5 Прогнать полный цикл: `pnpm verify` и `pnpm e2e`. Проверка: 90 юнит-тестов и 4 e2e зелёные.
- [x] 6.6 Снять скриншоты карты и базы для сверки художественного направления. Проверка: скалы читаются как гряда, силуэт базы опознаётся по антенне.
