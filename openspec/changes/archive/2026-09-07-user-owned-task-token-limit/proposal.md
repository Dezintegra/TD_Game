## Why

Задача 0233 исчерпала общий бюджет и спрашивает об увеличении, но ответ пользователя не меняет числовой предел. Нужен отдельный лимит карточки, которым распоряжается только пользователь.

## What Changes

- Точная команда владельца `Лимит токенов: 35000000` в новом комментарии Trello задаёт полный бюджет Codex для одной задачи; `Лимит токенов: общий` возвращает общий предел.
- Супервизор только читает команды пользователя из интерфейса Trello. API-комментарии, отчёты, заявки и машинный блок не являются источниками лимита; агенты не меняют его даже по текстовому поручению.
- Сканер и журнал используют один эффективный лимит. Неверное значение удерживает новые запуски без расхода попыток.
- Инструкция владельцу объясняет команду и возобновление ожидающей задачи.

## Capabilities

### New Capabilities

- `user-owned-task-token-limit`: индивидуальный бюджет Codex, изменяемый пользователем вне поверхности записи агента.

### Modified Capabilities

Нет.

## Non-goals

Разбор произвольного текста в разрешение на расходы, изменение лимита 0233 за пользователя, изменение общего лимита, сброс учёта токенов, автоматическое вливание чужих PR, изоляция от произвольного внешнего клиента с тем же токеном Trello.

## Impact

Затронуты чтение Trello, сканер, запуск и журнал Codex, инструкции и тесты supervisor. Игровой интерфейс и его отзывчивость не меняются. Трафик игры не меняется; чтение команд требует идентификации владельца токена и полной пагинации комментариев доски, чтобы старый лимит не исчез после тысячи записей. Новых зависимостей нет.
