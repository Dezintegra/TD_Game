# Задачи

## 1. Кирпичи: арифметика звука

- [x] 1.1 `audio/dsp.ts`: развёртка частоты, огибающие атаки и спада,
      фильтр состояния переменных (низ/полоса/верх), однополюсный
      низкочастотный, мягкое ограничение, нормировка к заданному пику.
      Шум берётся готовый — `noiseFrom` из `game/noise.ts`.
      Проверка: `dsp.test.ts` — фильтр не расходится и не даёт `NaN`
      на трёх секундах шума с бегущим срезом; спад монотонен;
      нормировка даёт ровно заданный пик; `softClip` не выходит
      за единицу ни на каком входе и расходится с настоящим тангенсом
      меньше чем на сотую.
- [x] 1.1б `audio/dsp.ts`: то, без чего не собрать взрыв, — резонатор
      (звон металла), рассыпанные толчки (обломки и электрические
      пробои), медленное качание громкости (раскат), насыщение.
      Проверка: резонатор нормирован по толчку и не уходит
      в ограничитель; фильтр не звенит на постоянном входе.
- [x] 1.1в `audio/dsp.ts`: скорость. Затухания шагами вместо `Math.exp`
      на каждом отсчёте, кеш настройки фильтра, дробно-рациональное
      приближение вместо `Math.tanh`.
      Проверка: выпечка всего набора укладывается в 900 мс вместо 1900.
- [x] 1.2 `audio/dsp.ts`: `zeroCrossings(samples, from, to)` — счётчик
      переходов через ноль на отрезке. Нужен не звуку, а тестам:
      это единственный способ проверить «тон падает» и «яркость
      уходит» арифметикой, а не ушами.
      Проверка: на синусе известной частоты счётчик даёт ожидаемое
      число с точностью до единицы.

## 2. Звуки событий

- [x] 2.1 `audio/sounds.ts`: каркас — перечень `Sound`, таблицы
      длительностей, относительных громкостей, числа вариантов
      и признака зацикленности; `renderSound(sound, variant, sampleRate)`.
      Длительности берутся из `SHOT_LIFETIME_TICKS`,
      `BLAST_LIFETIME_TICKS` и `NUKE_DELAY_TICKS` везде, где событие
      имеет срок в мире.
      Проверка: `sounds.test.ts` перебирает всю таблицу — первый
      и последний отсчёт равны нулю (кроме зацикленных), пик равен
      заявленному, `NaN` нет, длина соответствует длительности.
- [x] 2.2 Общее устройство взрыва: семь слоёв — кромка, тело, низ,
      отражение, обломки, металл, раскат. Четыре набора чисел:
      машина, генерал, постройка, ядерный удар.
      Проверка: у каждого взрыва фронт кратно громче хвоста — верх
      умирает быстрее низа; длительности упорядочены как
      `BLAST_LIFETIME_TICKS`; у постройки в хвосте отдельных всплесков
      от обломков кратно больше, чем у машины.
- [x] 2.3 Трассер: машинный и башенный. Тон падает с 1900 до 260 Гц
      за сотню миллисекунд, щелчок шума в начале; башенный ниже
      и в полтора раза длиннее.
      Проверка: переходов через ноль в последней четверти меньше,
      чем в первой; башенный звук длиннее машинного и ниже по числу
      переходов.
- [x] 2.4 Луч: три расстроенные пилы в биении сквозь полосу, съезжающую
      с 1900 к 700 Гц; башенный на кварту ниже.
      Проверка: огибающая имеет полку — среднеквадратичное значение
      в середине не меньше 80 % от максимума; в трассере это не так.
- [x] 2.5 Разряд Теслы: отдельные пробои в первые 85 мс сквозь три
      резонатора, шипящий хвост на срезе, падающем с 7000 до 210 Гц,
      низ и раскат.
      Проверка: переходов через ноль в последней четверти кратно
      меньше, чем в первой; длительность больше, чем у трассера.
- [x] 2.6 Ракета генерала: шум полосой, центр 600 → 2500 Гц, полёт
      ровно `SHOT_LIFETIME_TICKS[Missile]` × `MISSILE_FLIGHT_SHARE`,
      дальше приход в цель.
      Проверка: самый громкий отсчёт приходится на момент прилёта,
      а не на начало; первая четверть тише последней.
- [x] 2.7 Свист снижения ровно на `NUKE_DELAY_TICKS`: высота падает,
      громкость растёт.
      Проверка: среднеквадратичное значение последней четверти кратно
      больше первой; переходов через ноль в конце меньше, чем в начале.
- [x] 2.8 Ротор: петля ровно из семи периодов при 14 ударах в секунду.
      Проверка: длина ровно полсекунды при любой частоте
      дискретизации; конец сходится с началом — разница последнего
      и первого отсчёта меньше сотой.
- [x] 2.9 Варианты: у частых событий по три-четыре набора отсчётов
      с разным зерном.
      Проверка: два варианта одного звука не совпадают отсчёт
      в отсчёт, но совпадают по длительности и по пику.

## 4. Размещение и бюджет

- [x] 4.1 `audio/placement.ts`: `place(source, listener)` → громкость
      и панорама. Громкость `10 / (10 + d) · fadeOver(d, 22, 32)`
      с `fadeOver` из `game/effects.ts`; панорама по экранному
      смещению через `worldToScreen`, с потолком ±0.75.
      Проверка: `placement.test.ts` — убывание по удалению; ноль
      за отсечкой; ровно ноль в центре; панорама не выходит за ±0.75;
      источник слева даёт отрицательную панораму.
- [x] 4.1б `audio/reverb.ts`: отклик открытого поля — задержка,
      восемь ранних отражений на некратных временах, полторы секунды
      темнеющего хвоста; каналы от разных зёрен.
      Проверка: каналы не совпадают (иначе отклик слышен посередине
      головы); начинается с задержки; затухает монотонно по четвертям;
      к концу темнеет.
- [x] 4.1в Живое размещение: `place` считается каждый кадр для каждого
      звучащего источника, параметры едут не присваиванием, а слежением.
      Проверка: `placement.test.ts` — прокрутка карты меняет знак
      панорамы у неподвижного источника.
- [x] 4.2 `audio/budget.ts`: потолки на вид и общий, отбор ближайших,
      прибавка `min(1.6, sqrt(всего / оставлено))`.
      Проверка: `budget.test.ts` — потолки соблюдаются; отобраны
      ближайшие; прибавка не превышает 1.6; пустой вход даёт
      пустой выход; ровно один источник не получает прибавки.

## 10. Долг, оставленный сознательно
