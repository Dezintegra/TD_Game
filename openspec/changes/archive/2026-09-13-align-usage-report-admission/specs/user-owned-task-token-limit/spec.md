## MODIFIED Requirements

### Requirement: Гейт и журнал используют эффективный бюджет

Система MUST использовать пользовательский предел вместо общего для обычных запусков Codex и указывать его в журнале этапа. Неверное значение MUST удерживать обычные запуски без изменения попыток. Новый предел MUST NOT отменять зависимости, известный расход, диагностику неполноты или замечания ревью. Неполнота учёта сама по себе MUST NOT удерживать запуск или отменять завершённый отчёт. Команда в awaiting-po MUST учитываться штатным обработчиком ответа.

#### Scenario: Возобновление после исчерпания

- **WHEN** расход 26093350, общий лимит 25000000 и пользователь задаёт 35000000 в ожидающей карточке
- **THEN** ответ возвращает карточку на сохранённый этап, последующие обычные этапы допускаются при выполнении остальных условий, журнал показывает 35000000

#### Scenario: Неверная сумма

- **WHEN** последняя человеческая команда содержит ноль, отрицательное, дробное или небезопасное целое
- **THEN** обычный запуск удерживается с понятной причиной до новой корректной команды
