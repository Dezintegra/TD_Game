## 1. Короткие команды коммита во всех трёх скиллах

- [ ] 1.1 Одним атомарным коммитом (до 2 часов) обновить разделы коммита в `supervisor/skills/design.md`, `supervisor/skills/implement.md`, `supervisor/skills/revise.md`: приблизительное наблюдение около 965 байт с источником и оговоркой о непроверенной точной границе; диагностика `Command too long for parsing` до Git; бесполезность добавления allow; полный состав длины команды; мерка абзаца в две-три короткие фразы без гарантии; короткий однострочный образец с `git -C <дерево> commit` и осмысленным «почему». Сохранить повторные `-m` и запрет многострочного тела. Направить подробности в файл тела PR через `--body-file`, а в design сначала в собственный `design.md`. Проверка: прочитать каждый раздел по всем четырём сценариям дельты, выполнить `npx prettier --check supervisor/skills/design.md supervisor/skills/implement.md supervisor/skills/revise.md` после форматирования только затронутых файлов и `git -C <дерево> diff --check`. Немедленно отправить коммит и открыть черновой PR по правилам implement. В тело PR включить подробное обоснование и протокол последующего наблюдения из design.md, явно отделив его от уже выполненных проверок.
