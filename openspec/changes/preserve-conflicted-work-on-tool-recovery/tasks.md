## 6. Правила каждого коммита

Каждый пункт выше — отдельный самостоятельно проверяемый коммит с немедленной отправкой. `<дерево>` во всех Git-командах — назначенное дерево 0381, кроме явно read-only адресных команд из design. Пути добавлять явным перечнем, допускающим рабочие изменения пункта и его обязательную отметку в `openspec/changes/preserve-conflicted-work-on-tool-recovery/tasks.md`. Перед коммитом проверять `git -C <дерево> diff --cached --name-only` и `git -C <дерево> diff --cached`; после — `git -C <дерево> show --stat HEAD` и `git -C <дерево> show HEAD`. Проверять и пути, и содержание; `.matchlog/` и любые чужие правки в индекс/коммит не включать. Выполнить `git -C <дерево> push` немедленно после каждого коммита. Проверки OpenSpec: `openspec validate preserve-conflicted-work-on-tool-recovery --strict` и `openspec status --change preserve-conflicted-work-on-tool-recovery`.

CI опрашивает супервизор. Здесь нет пункта ожидания CI, архивации, завершения соседних PR, снятия паузы или ручного изменения доски. Приёмка 5.1/5.2 не закрывается передачей обещания выполнить её позже. Предел времени пункта — повод сохранить промежуточные результаты и точную преграду; не основание пометить недоказанный результат выполненным.
