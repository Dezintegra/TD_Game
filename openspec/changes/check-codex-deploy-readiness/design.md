## Context

PR #148 проверяет реальные команды Git и GitHub внутри Codex. На Windows elevated sandbox запускает команды от отдельного пользователя: SSH не находит пользовательский псевдоним dezintegra. Две карточки получили failed из-за одной неисправности среды.

## Goals / Non-Goals

До назначения задач убедиться в доступности целевого SSH-сервера из той же среды. Не менять SSH-учётные данные, разрешения sandbox и сервер.

## Decisions

Дополнить существующую пробу третьей отдельной командой SSH, сохранив общий таймаут 120 секунд. Использовать TD_DEPLOY_HOST из окружения пробы или dezintegra, как scripts/deploy.mjs. BatchMode и ConnectTimeout=15 исключают ожидание ввода; StrictHostKeyChecking=yes исключает автоматическое доверие неизвестному серверу. Сервер выполняет только printf с фиксированным маркером. Успех требует completed/exit 0 и маркера в выводе именно команды SSH к нужному хосту. Ошибка и отсутствие команды блокируют готовность. Произвольный текст модели доказательством не является.

Проверка от владельца процесса отвергнута: она не воспроизводит права sandbox. Автоматическая выдача прав к .ssh отвергнута: это отдельное изменение доступа к секретам.

## Risks / Trade-offs

Недоступность SSH остановит весь старт Codex, включая проектирование. Это намеренная проверка готовности полного конвейера; причина сохраняется в codex-readiness.log и pause. Проба доказывает соединение, но не права docker и успешность будущей выкладки.

## Migration Plan

Узкие тесты и реальная отрицательная проба на текущей машине, затем CI и merge. До настройки SSH конвейер остаётся на ручной паузе. Для отката вернуть проверку к Git/GitHub; права и сервер не меняются.

## Open Questions

Доступ к конфигурации и ключу развёртывания из sandbox требует отдельного решения владельца. Данная правка его не предоставляет.
