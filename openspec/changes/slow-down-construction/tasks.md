      к тику `elapsed`, минус то же для `elapsed - 1`. `elapsed`
      выводится из `builtAtTick` и текущего тика — нового поля
      в состоянии заводить не нужно.
      _Проверка:_ арифметика целая, `Math.ceil` из функции исчез.
- [x] 2.2 Тест: снайперская башня на середине возведения имеет прочность
      заметно меньше максимальной. Это тот случай, который ломается
      нынешним округлением: он добирал максимум за 120 тиков из 270.
      _Проверка:_ тест зелёный; при откате правки 2.1 падает.
- [x] 2.3 Тест: к последнему тику возведения набрано ровно столько,
      сколько нужно, — ни больше, ни меньше, для всех трёх построек.
      _Проверка:_ прочность равна максимальной ровно на `builtAtTick`.
- [x] 2.4 Тест: постройка, получившая урон во время возведения,
      продолжает набирать по расписанию и не «долечивается».

      урона.
