# Задачи

Каждая — отдельный коммит, отправляемый сразу. Порядок выбран так, чтобы
любая остановка оставляла работоспособное состояние: после первой задачи
поле уже чёрное, после второй сетка уже слушается режима, и мгла
пристраивается к готовому.

Черновой pull request открывается **сразу после задачи 1**: до его
появления пуши в ветку не запускают в CI ничего вовсе.

**Незакрытые пункты и почему.** Всё, что требует живого приложения —
снимки Playwright (2.3, 4.4, 5.1) и замер кадров, — в сессии
имплементации от 02.09.2026 сделать не удалось: правила разрешений
не пропустили ни `pnpm install` (без него в рабочем дереве нет
`node_modules`), ни `npx vite`, ни `npx playwright`. Узкие проверки,
которые разрешены, — `npx eslint`, `npx prettier`, `npx vitest` — прогнаны
и зелены по журналу того захода; на проработке они не повторяются.
Замер кадров не принадлежит этапу имплементации: его условия сохранены
ниже без исполняемых галочек. Снимки остаются открытыми: передача проверки
другой задаче сама по себе не доказывает её выполнения.

**Возобновление 06.09.2026.** Продолжается PR #110 и существующая реализация.
Новый PR и повторная реализация отмеченных пунктов не нужны. Отказы установки
02.09 — исторический факт: текущий `supervisor/config/stage-settings.json`

Каждый оставшийся пункт рассчитан максимум на два часа и отдельный коммит
