# Задачи

Каждая — отдельный коммит, отправляемый сразу. Порядок выбран так, чтобы
любая остановка оставляла работоспособное состояние: после первой задачи
поле уже чёрное, после второй сетка уже слушается режима, и мгла
пристраивается к готовому.

Черновой pull request открывается **сразу после задачи 1**: до его
появления пуши в ветку не запускают в CI ничего вовсе.

## 3. Раскладка и движение мглы (без подключения к сцене)

- [ ] 3.1 `apps/client/src/game/clouds.ts`: чистые функции —
      `cloudPuffs(timeMs, cameraOffset, viewport)` возвращает массив
      размещений (положение, поворот, масштаб, прозрачность, номер
      варианта текстуры). Всё выводится из номера пятна через `hashOf`
      из `noise.ts`; `Math.random` не используется. Константы
      с обоснованием: предел числа пятен, скорости дрейфа и поворота,
      периоды «дыхания» (взаимно не кратные), множитель параллакса.
- [ ] 3.2 Тесты `clouds.test.ts`: число пятен не превышает предела при
      любом размере окна и любом смещении камеры; два вызова с тем же
      временем совпадают до числа; за секунду положение, поворот
      и масштаб изменились; смещение камеры сдвигает пятна меньше, чем
      на само смещение; рамка экрана покрыта — в каждой её четверти
      есть хотя бы одно пятно.
      Проверка: `npx vitest run apps/client/src/game/clouds.test.ts`.

- [ ] 4.4 Проверить снимком: за краем карты клубы видны, внутри границ
      карты мглы нет ни в одной точке; на снимках, снятых с промежутком
      в несколько секунд, картина мглы отличается.
      Проверка: снимки приложены к комментарию PR.

## 5. Отражения на чёрном поле

- [ ] 5.1 Снять снимок с юнитом и скальной грядой на чёрном поле,
      сравнить яркость отражения с яркостью чистого поля рядом. Числа

      поднять `MIRROR_KEEP` (`models.ts`) и/или
      `ROCK_MIRROR_STRENGTH` (`relief-render.ts`), не переходя потолка
      «больше четверти — уже вторая машина». Правку сопроводить
      замеренными числами до и после. Если снимок 5.1 показал, что
      всё в порядке, — шаг закрывается записью «не потребовалось».
