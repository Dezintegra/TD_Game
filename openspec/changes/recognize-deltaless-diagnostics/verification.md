## Разбор матрицы по инструкциям

Вход — полный контрольный вывод OpenSpec 1.6.0 из design.md, включая заголовок,
Ensure your change…, Tip: run… и весь Next steps. Это зафиксированное в проработке
воспроизведение структуры вывода владельца, а не новая живая проба CLI.
Для положительных случаев заданы отсутствие specs/, точный раздел proposal.md
и содержательно подтверждённое обоснование. Допуск означает только исключение
к ошибке формы; прочие проверки этапа обязательны.

Каждый случай ниже отдельно сопоставлен с окончательным фрагментом
«Исключение для отсутствия дельт» в design.md и audit.md. Это ручной разбор
инструкций, не запуск автономных этапов и не тест выдуманного парсера.

| Случай | Решение design и основание | Решение audit и основание |
| --- | --- | --- |
| Полный контрольный вывод | Допустить: начало сообщения совпало, ошибка одна, все перечисленные пояснения разрешены | Допустить: заголовок и подсказки не добавляют ошибок; содержательное обоснование независимо подтверждено |
| Только ERROR с полным началом без пояснений | Допустить: подсказки разрешены, но не обязательны | Допустить: единственная ошибка имеет нужное начало, условия выполнены |
| Полный вывод плюс ERROR Requirement must have at least one scenario перед Next steps | Не допустить: ошибок две | Не допустить: дополнительная ошибка требует обычного замечания |
| Та же дополнительная ошибка после списка Next steps | Не допустить: явно требуется просмотреть вывод до конца | Не допустить: расположение после Next steps не отменяет вторую ошибку |
| Единственная ошибка Delta parsing found no operations | Не допустить: другое начало сообщения | Не допустить: другая ошибка исключением не покрывается |
| Нужная цитата только в Tip, единственная ошибка другая | Не допустить: сравнивается начало сообщения ошибки | Не допустить: цитата только в подсказке явно недостаточна |
| Полный вывод, specs/ существует и пуст | Не допустить: требуется отсутствие каталога, пустой явно исключён | Не допустить: независимое обязательное условие нарушено |
| Полный вывод, нужного раздела в proposal.md нет | Не допустить: обязательного раздела нет | Не допустить: отсутствующий раздел исключает применение |
| Полный вывод, заголовок есть, обоснование пустое | Не допустить: пустой раздел явно запрещён | Не допустить: одного заголовка недостаточно |
| Полный вывод, обоснование заявлено, задача меняет требование | Не допустить: обоснование опровергнуто содержательной сверкой | Не допустить: независимая сверка выявляет изменение прочтения требования, требуется замечание |
| Полный вывод, обоснование ещё не проверено | Не допустить до проверки по задачам, основе и открытым дельтам | Не допустить до независимой содержательной сверки |

Все 11 случаев совпали с ожиданиями для каждого этапа.
