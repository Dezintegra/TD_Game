## Правила каждого коммита

Допустимы только рабочие файлы, явно перечисленные в своём пункте, и отметка этого пункта в openspec/changes/preserve-stage-attempt-logs/tasks.md. Пути добавлять явным списком через `git -C <дерево> add -- <свои пути>`. До коммита проверить имена и содержимое `git -C <дерево> diff --cached`, после — `git -C <дерево> show --stat --oneline HEAD` и `git -C <дерево> show HEAD`. Исключить временные тестовые файлы и несвязанные изменения даже внутри разрешённых путей. Каждый пункт — самостоятельный коммит с немедленным `git -C <дерево> push`.

Команды pnpm test:pipeline покрыты PowerShell(pnpm test:pipeline:*) в supervisor/config/stage-settings.json; Git вызывается через -C. На design эти проверки не исполняются. Перед отчётом реализации проверить `openspec validate preserve-stage-attempt-logs --strict`. Ожидание CI, арена, выкладка и запуск живого супервизора в задачи не входят.
