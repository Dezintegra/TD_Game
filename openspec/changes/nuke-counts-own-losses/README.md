# nuke-counts-own-losses

Выбирая точку удара, противник вычитает из счёта своих **юнитов** —
и не смотрит ни на свои постройки, ни на своего генерала. Взрыв
уничтожает и то, и другое.

Замер на 24 зеркальных матчах (seed 3000–3023, код `62ec9682`,
158 принятых ударов): каждый удар в среднем сносит **1,09 своей
постройки**, и в **45 случаях из 158** гибнет собственный генерал.

Механизм понятен и повторяем: генерал — вторая по важности цель для
всего стреляющего, поэтому самая плотная толпа врагов почти всегда та,
что дерётся с собственным генералом. По ней противник и бьёт.

**Отношение к `fix-ai-spending`.** Правка живёт в той же функции
`tryNuke`, которую то изменение переписывает: там порог удара выводится
из цены, здесь в тот же счёт добавляются свои потери. Если то изменение
ещё не реализовано, разумнее внести это требование прямо в него;
отдельным оно заведено потому, что найдено отдельным замером
и обосновано самостоятельно.
