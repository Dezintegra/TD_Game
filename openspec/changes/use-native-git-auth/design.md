## Context

PR #148 использует credential helper !gh auth git-credential через sh.exe. На Windows unelevated sandbox SSH работает, но запуск MSYS-оболочки падает с Win32 error 5. Git и gh по отдельности запускаются нормально.

## Goals / Non-Goals

Восстановить git push без ослабления sandbox и без раскрытия токена. Режим sandbox выбирается существующей настройкой; параметры сервера и токены не меняются.

## Decisions

Передать GIT_CONFIG_COUNT/KEY_n/VALUE_n окружением непосредственно каждому процессу Codex. Последовательность конфигурации: сброс safe.directory, два точных пути root/cwd, сброс GitHub credential.helper, сброс GitHub extraHeader и Authorization Basic для x-access-token. HTTP-заголовок ограничен https://github.com/. Токен берётся из уже разрешённого GH_TOKEN; не попадает в argv, prompt или файлы. Входные GIT_CONFIG_* счётчики, значения и GIT_CONFIG_PARAMETERS удаляются перед сборкой, чтобы не наследовать посторонние настройки. GIT_TERMINAL_PROMPT=0 исключает fallback к диалогу. Окружения задач независимы; общий объект не мутируется. Claude не затрагивается.

Удалить прежнюю настройку Git из CLI -c shell_environment_policy.set и добавление Git bin в PATH ради sh. Проба готовности и рабочие этапы используют один построитель окружения.

В пробе добавить git push --dry-run в refs/heads/codex/readiness через выбранный remote. Команда не меняет удалённую ветку. Успех требует выполненной команды с кодом 0, дополнительно к Git/GitHub/SSH. Публичный fetch не доказывает возможность отправки и потому не подходит. Общий лимит пробы остаётся 120 секунд.

## Risks / Trade-offs

Любой дочерний процесс Codex наследует GitHub-авторизацию, как и прежний GH_TOKEN. Не выводить окружение в диагностике. Git config --list также может показать заголовок; такие команды не использовать для проверок. Логи проб хранят только стандартные результаты Git, без trace/curl verbose.

## Migration Plan

Узкие тесты и настоящая dry-run отправка из отдельного дерева с новым адаптером; CI; merge; перенос ожидающих отчётов старым супервизором; штатное самообновление на локальной конфигурации Codex. Затем подтвердить рабочие этапы. При откате вернётся старый helper и известная несовместимость unelevated; секреты и глобальные настройки не затронуты.
