## Context

Windows готовит файловые разрешения для рабочего каталога при первом обращении. Проверка из temp не подготавливает основной корень, где начинается decompose.

## Goals / Non-Goals

Подготовить реальный корень до работы модели. Не расширять профиль и не менять Linux-проверку.

## Decisions

На Windows прямой codex sandbox запускает Node с фиксированным маркером готовности. Используется codexExecutionArgs и профиль td-pipeline, тот же корень и окружение. Срок десять минут покрывает наблюдавшиеся пять минут подготовки, после него старт завершается ошибкой. Только code=0 без тайм-аута и точный маркер разрешают последующую проверку модели. Увеличение срока самой задачи не решает ранний failed агента; прямой вызов исключает это решение модели.

## Risks / Trade-offs

Первый запуск может занять несколько минут до выдачи карточки. Сбой виден как ошибка среды и сохраняет задачи нетронутыми. Тёплый запуск подтверждён реальной командой за678мс. Холодную проверку потребуется наблюдать при следующей подготовке, без сброса рабочих ACL.

## Migration Plan

Узкие тесты порядка и отказов, реальная команда Windows, CI, слияние и штатное обновление.
