# Шаги реализации

Каждый шаг — отдельный коммит, отправляемый сразу. Все проверки узкие
и идут по своим файлам: матчей это изменение не играет ни одного, арену
не запускает и `packages/*` не трогает.

Общая команда проверки для всего списка:

```bash
npx vitest run --root scripts
```

## 1. Ошибка доли

- [ ] 1.1 Завести `scripts/balance-stats.mjs` с чистой функцией ошибки
      доли по поправке Агрести — Коулла: `p̃ = (x + 2) / (n + 4)`,
      `se = √(p̃(1 − p̃)/(n + 4))`. Ввод — число матчей и число матчей
      с таким исходом; ни файлов, ни git, ни базы. Проверяемо:
      `scripts/balance-stats.test.mjs` зелёный, и в нём есть случай
      `x = 0`, где ошибка строго больше нуля и составляет около
      2,2 пункта при `n = 60`

**После этого шага открывается черновой pull request.** До его открытия
CI на пуши в ветку не запускается вовсе, и остальные шаги остались бы
непроверенными.

```bash
gh pr create --draft --base main --title "Сдвиг баланса судится по своей ошибке"
```

## 2. Ошибка медианы

- [ ] 2.1 Точный хвост биномиального распределения `Bin(n, ½)`: счёт
      от середины ряда наружу по отношению соседних членов, с накоплением
      относительных весов и нормировкой их суммой. Проверяемо: тест
      сверяет значения при `n = 10` с точными долями (`P(X ≤ 2) = 56/1024`,
      `P(X ≤ 3) = 176/1024`) и не переполняется при `n = 4000`
- [ ] 2.2 Ошибка медианы по порядковым статистикам: 68-процентный
      интервал `[x₍ₖ₊₁₎, x₍ₙ₋ₖ₎]`, ошибка — бо́льшая из двух половин.
      Проверяемо: на выборке из двух далёких горбов (часть значений около
      4500 тиков, часть у потолка 36000) ошибка выходит порядка минут,
      а не секунд; на выборке из одинаковых чисел — ноль

## 3. Мерка: различимость и заметность

- [ ] 3.1 Ошибка разницы `√(se_было² + se_стало²)` и допущение о старой
      записи: ошибки «было» нет — берётся равной нынешней, и функция
      возвращает признак того, что допущение применялось. Проверяемо:
      тест на паре, где ошибка «было» отсутствует, даёт ровно `√2 · se`
      и поднятый признак
- [ ] 3.2 Приговор по сдвигу: отношение к ошибке разницы плюс порог
      заметности, три ступени — «говорить не о чем», «на грани»,
      «расхождение». Расхождение объявляется, только когда пройдены
      **обе** мерки. Проверяемо: тест на четырёх случаях — значимо
      и заметно; значимо, но мелко; заметно, но неразличимо; ни то ни
      другое

## 4. Подключение к прогонщику

- [ ] 4.1 Перевести `divergences()` в `scripts/balance-run.mjs` на новую
      мерку. Константы `WIN_SHARE_STEP`, `LENGTH_STEP`,
      `REASON_SHARE_STEP` остаются и становятся порогами заметности;
      комментарий над ними переписать — нынешний утверждает, что шума
      здесь нет вовсе, и следующий читатель по нему снова решит, что
      задача не нужна. Проверяемо: `npx eslint scripts/balance-run.mjs`
      чист, `npx vitest run --root scripts` зелёный
- [ ] 4.2 Тест на замороженном снимке истории: пара записей
      `compact-map-tempo` от 25.08.2026 и 26.08.2026, литералами в тесте,
      а не чтением живого журнала. Проверяемо: ни одного расхождения,
      и по каждой из четырёх прежде объявленных величин отношение сдвига
      к ошибке меньше двух
- [ ] 4.3 Тест на заведомо разошедшихся данных: величина сдвинута
      настолько, что превышает и три ошибки, и порог заметности.
      Проверяемо: расхождение объявлено ровно по ней одной
