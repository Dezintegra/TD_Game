Перед коммитом проверить `git -C <дерево> diff --cached --name-only` и `git -C <дерево> diff --cached`: только заказанная правка и её отметка, никаких чужих изменений. После коммита немедленно отправить его, проверить `git -C <дерево> show --format=fuller HEAD` и `git -C <дерево> diff-tree --no-commit-id --name-only -r HEAD`: те же допустимые пути и содержание; `.matchlog/0199-commit-message.txt` и любой собственный файл тела PR отсутствуют и в индексе, и в созданном коммите.
