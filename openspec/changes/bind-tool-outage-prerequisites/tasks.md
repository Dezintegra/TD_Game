## Приёмка после отчёта implement

Супервизор применяет dependencyUpdates и независимо читает адресата до перехода источника. Следующий review проверяет в переданном журнале подтверждение обеих пар, сохранности остальных данных и освобождения только собственного временного захвата. Без подтверждения запись не считается завершённой. Отдельно фиксирует свежий доступный результат штатного допуска либо «не подтверждён» с причиной; awaiting-po не меняется. При недостающих свидетельствах приёмку не объявлять успешной и не восполнять их ручной записью. Это обязанность приёмки после доставки, а не пункт ожидания собственной сессии implement. Для завершения операции не требуются вливание PR 172, закрытие всех предшественников или фактический запуск 0244.
