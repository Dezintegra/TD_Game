## Why

Выкладка 0202 остановилась после успешной установки пакетов: инструкция требует на игровом сервере все имена из общего `.env.example`, включая ключи локального Trello и необязательную TELEMETRY с явным значением по умолчанию. Это ложный вопрос владельцу и препятствие автономной выкладке.

## What Changes

- Проверять только настройки, используемые запускаемыми сервисами.
- Учитывать документированные значения по умолчанию и сохранять явные серверные настройки.
- Спрашивать только о действительно обязательной настройке без определённого значения.

## Capabilities

### New Capabilities

- `deploy-runtime-env`: проверка применимости серверных настроек перед выкладкой.

### Modified Capabilities

Нет.

## Impact

Общая инструкция deploy для Claude и Codex. Поведение игры, отзывчивость и сетевой трафик не меняются.

## Non-goals

Изменение значений серверного `.env`, копирование Trello-секретов на сервер, изменение политики телеметрии или замеров.
