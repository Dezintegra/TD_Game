## ADDED Requirements

### Requirement: Ожидание хранится в едином графе с результатом

Найденное на этапе предусловие SHALL записываться в существующие dependsOn/dependencyResults и blockedContext. Обычная очередь не заменяет ожидание. Освобождение назначения SHALL завершаться устойчивой доставкой отчёта; рабочее дерево и ветки сохраняются. Отсутствие owner не даёт другой машине права на чужое дерево.

#### Scenario: Предмет ещё не влит
- **WHEN** design либо implement обнаружил обязательную невыполненную работу
- **THEN** карточка ожидает в blocked; причина, источник и результат сохраняются на доске после перезапуска

#### Scenario: Зависимость дала требуемый результат
- **WHEN** штатная проверка подтвердила результат и граф больше не блокирует задачу
- **THEN** допускается новый анализ по обычному маршруту с сохранёнными артефактами

#### Scenario: Предшественник закрыт без результата
- **WHEN** снято ребро закрытой карточки без преемника и результат не доказан
- **THEN** сохраняется dependencyRecheck; перед работой требуется доказательный пересмотр условия либо живая замена

#### Scenario: Работа передана преемнику
- **WHEN** закрытая карточка передала требования через splitInto
- **THEN** зависимая задача ждёт выполнения преемника; закрытие исходника не считается результатом

#### Scenario: Ошибка графа
- **WHEN** зависимость отсутствует, двусмысленна либо образует цикл
- **THEN** запуск удерживается с конкретной диагностикой; требование не снимается молча
