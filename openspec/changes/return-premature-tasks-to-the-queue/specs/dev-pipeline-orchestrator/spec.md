## ADDED Requirements

### Requirement: Повторное взятие сохраняет своё рабочее дерево

Перед созданием дерева оркестратор SHALL читать фактическую опись Git. Совпадение ожидаемого абсолютного пути и ветки SHALL позволять повторное взятие без второго worktree add. Совпадение имени каталога без подтверждения ветки недостаточно.

#### Scenario: Своё дерево уже существует
- **WHEN** Git подтверждает дерево по ожидаемому пути на ожидаемой ветке
- **THEN** оркестратор возвращает существующий путь и не создаёт другое дерево

#### Scenario: Чужая или отсоединённая ветка
- **WHEN** ожидаемый путь занят другой веткой либо detached HEAD
- **THEN** запуск отклоняется с диагностикой без изменения дерева

#### Scenario: Ветка выложена по другому пути
- **WHEN** Git сообщает ожидаемую ветку в другом дополнительном дереве
- **THEN** новое дерево не создаётся; возвращается диагностируемый отказ для штатной сверки фактического пути

#### Scenario: Опись недоступна
- **WHEN** чтение worktree list завершилось ошибкой
- **THEN** создание не предпринимается, ошибка доходит до вызывающего

#### Scenario: Дерева ещё нет
- **WHEN** опись не содержит ни ожидаемого пути, ни занятой ожидаемой ветки
- **THEN** прежнее создание от существующей ветки или origin/main сохраняется
