## 2. Границы коммита и проверки

Разрешены только рабочие правки в трёх перечисленных файлах и отметка выполнения в `openspec/changes/distinguish-benchmark-perf-commands/tasks.md`. Каждый путь добавить явным списком; постороннее содержание внутри этих путей тоже запрещено. Исходные OpenSpec-артефакты уже сохранены этапом design.

До коммита проверить имена и полный diff: `git -C <дерево> diff --cached --name-only` и `git -C <дерево> diff --cached`. После создания проверить `git -C <дерево> show --stat --oneline HEAD` и `git -C <дерево> show --format=fuller HEAD`, затем сразу `git -C <дерево> push`. Не включать вспомогательные временные файлы. Проверки выполняются отдельными вызовами из назначенного дерева; необходимые зависимости готовятся штатным порядком implement. Полный verify, замеры и арена не нужны для локальной проверки этой правки.

Вливание и последующая проверка PR 219 описаны в Migration Plan design.md и принадлежат следующим назначенным сессиям. Они не являются пунктами tasks.md, которые implement обязан закрыть до собственного PR. Наблюдение CI выполняет супервизор. Завершение реализации не подменяет подтверждение применения исправления к PR 219.
