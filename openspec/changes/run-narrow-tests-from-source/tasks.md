## Правила коммитов и границы

Все команды выполняются из назначенного дерева, отдельными вызовами. Начальная установка реализации — `pnpm install --frozen-lockfile --prefer-offline`. Новые тесты scripts имеют суффикс .test.mjs и запускаются с `--root scripts`; supervisor — с `--root supervisor`.

Каждый пункт — отдельный проверяемый коммит с немедленным push. К рабочим путям каждого пункта всегда разрешена только его отметка в `openspec/changes/run-narrow-tests-from-source/tasks.md`. Добавлять явным перечнем через `git -C <дерево> add -- <пути>`, проверить имена и содержание `git -C <дерево> diff --cached`, затем после коммита `git -C <дерево> show --stat HEAD` и `git -C <дерево> show HEAD`, отправить `git -C <дерево> push`. Несвязанные изменения даже в разрешённых путях запрещены. Собственные .matchlog-копии, отчёты, переходник и тело PR не входят в индекс/коммиты; проверять их фактические пути отдельно, не общее количество файлов. Временные изменения исходников существуют только в собственной проверочной копии.

Пробу исходного implement 0013 проводит её назначенная сессия после доставки ремонта по механизму инцидентов; это не открытый checkbox служебной имплементации, не ожидание CI и не разрешение перехватить карточку. Прогоны арены 0331/0332 остаются у 0013; новых заказов нет. На design выполняются только validate/status документов, ни одна проверка реализации из этого списка сейчас не запускается.
