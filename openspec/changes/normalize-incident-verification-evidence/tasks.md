## Граница этапов и живая приёмка

Каждый checkbox — отдельный проверяемый коммит с собственной отметкой. Команды выполняются отдельными вызовами из назначенного дерева; `.` в `git -C .` обозначает это дерево. Запрещены посторонние правки внутри разрешённых файлов, `git add -A`, полный verify, матчи и ожидание CI. OpenSpec проверяется `openspec validate normalize-incident-verification-evidence --strict` и `openspec status --change normalize-incident-verification-evidence`.

Восстановление живой 0199 после загрузки ремонта относится к владельцу данных супервизора, не является checkbox для implement и не требует новой карточки/проработки. Его обязательный результат: исходный design запуска `34ba94e3-40a8-409b-a8ad-c1193e043888` штатно проверен и применён в audit, сохранены `pass-commit-messages-by-file`, `ac8a349ea764e6687fe982da2544a2c49f398f8b`, `048143908a2ccf31fe63bb59722a9a8a93a2d6e1`, все свидетельства и расход. До подтверждения результата инцидент остаётся активным. При недостающей улике назвать её и сохранить ожидание без нового design.
