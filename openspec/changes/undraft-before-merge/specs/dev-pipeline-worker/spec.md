## ADDED Requirements

### Requirement: Ревью снимает черновой статус перед вливанием

Правила этапа `review` SHALL предписывать сессии снять с pull request
черновой статус (`gh pr ready <pr>`) до вызова `gh pr merge`.

Черновой статус SHALL сниматься только после вынесенного вердикта «вливать»,
то есть при одновременно выполненных трёх условиях — зелёные проверки CI,
отсутствие замечаний, отсутствие конфликтов с `main`. Сессия MUST NOT снимать
черновой статус с pull request, который она возвращает в доработку: черновик
означает «работа не закончена», и снятый раньше времени, он вводит в
заблуждение и человека, и следующую сессию.

Состояние черновика SHALL читаться тем же обращением, которым сессия
проверяет, не влит ли pull request уже (`gh pr view <pr> --json state,isDraft`).
Команда `gh pr ready` SHALL вызываться, только когда `isDraft` истинно:
поведение `gh pr ready` на нечерновом pull request правилами этапа
не оговаривается и на нём не строится.

Требование написано по следам задачи 0130 (03.09.2026): вливание отбилось
ответом `GraphQL: Pull Request is still a draft (mergePullRequest)` при
полностью готовой и одобренной работе, и прошло лишь после команды,
набранной помимо скилла.

#### Scenario: Вердикт «вливать» на черновом pull request

- **WHEN** ревью вынесло вердикт «вливать», а `gh pr view` вернул
  `isDraft` истинным
- **THEN** сессия сначала зовёт `gh pr ready <pr>`, и лишь затем `gh pr merge`
- **AND** вливание не отбивается ответом о черновике

#### Scenario: Pull request уже не черновик

- **WHEN** ревью вынесло вердикт «вливать», а `gh pr view` вернул
  `isDraft` ложным
- **THEN** сессия зовёт `gh pr merge` сразу, не трогая черновой статус

#### Scenario: Изменение уезжает в доработку

- **WHEN** ревью выставило замечание либо нашло конфликт с `main`
- **THEN** черновой статус с pull request не снимается
- **AND** сессия завершается исходом `rejected`, не зовя ни `gh pr ready`,
  ни `gh pr merge`

#### Scenario: Проверки сняты с черновика и остаются в силе

- **WHEN** проверки CI позеленели, пока pull request был черновиком,
  и после этого сессия сняла черновой статус
- **THEN** повторного прогона проверок не начинается, и ревью вливает
  по уже снятым показаниям
