# Список задач

Каждый шаг — отдельный коммит, собирающийся и проверяемый сам по себе.
Проверка сторожами гоняется командой `pnpm test:pipeline` (это
`vitest run --root supervisor`; обычный прогон тестов этих файлов
не видит).

## 1. Скилл проработки называет случай, когда дельты не будет

- [x] В `supervisor/skills/design.md`, шаг 8, добавить случай «дельта
      не нужна»: правило («дельта пишется, когда правка вводит правило,
      которому обязано подчиняться будущее; дельты нет, когда правка
      приводит единичный текст в согласие с тем, что уже решено») и
      проверяемый признак («после правки ни одно требование
      в `openspec/specs/` и ни одна открытая дельта не читаются иначе,
      чем до неё»).
- [x] В шаг 7 (предложение) добавить обязательный для этого случая раздел
      `## Почему дельты нет`: какие требования правка задевает и почему

      проработки содержит `## Почему дельты нет`.
