# honor-profile-preferences

Профиль объявляет состав войска и порядок прокачки. Ни то, ни другое
не исполняется.

Поздняя фаза просит треть гранатомётчиков — за 24 матча заказано ноль.
Фазы называют восемь целей прокачки — куплены две. Обе беды механические:
`tryTrain` копить не умеет вовсе, а перебор целей в `tryUpgrade`
обрывается на первой, где нашлась хоть одна ветка, — и ветки
не кончаются никогда.

Всё измерено ареной на 24 зеркальных матчах, seed 3000–3023,
код `62ec9682`, дерево чистое. Числа — в `proposal.md`.

**Профилем это не лечится, и это проверено.** Кандидат с экономикой
во главе списка поздней фазы дал доход 26,60 против 14,65 — и ноль
боевой прокачки за весь матч. Список выродился в другую сторону.
Порядок, который всегда выбирает первый пункт, порядком предпочтения
не является.

**Осторожно с успехом.** Заявленный состав войска, судя по замеру, сам
по себе плох: опыт с принудительными гранатомётчиками уронил снятое
с базы здоровье с 17,3% до 5,4%. Механизм и числа надо чинить порознь
и в этом порядке — сначала механизм, потом замер, потом числа. Иначе
исправная механика разгонит негодную настройку.

**Порядок.** Независимо от `fix-ai-spending`, но мерить по очереди:
оба изменения трогают траты, и одновременный замер не разобрать.
