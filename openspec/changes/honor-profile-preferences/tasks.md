# Задачи

Идёт **после** `fix-saving-patience`: без исправленного предела терпения
накопление на дорогого юнита всё равно не доводится до конца, и правку
нечем будет увидеть.

## 1. Мерило

- [ ] 1.1 Добавить в сводку матча состав заказанных юнитов по типам
      рядом с заданными профилю весами.
      *Проверка:* на базовой линии видно 91% штурмовиков против
      заявленных 44% и ноль гранатомётчиков против заявленной трети.
- [ ] 1.2 Добавить в сводку покупки прокачки по целям.
      *Проверка:* на базовой линии видны две цели из восьми.
- [ ] 1.3 Снять линию на seed 3000–3023 уже с исправленным терпением —
      это и есть точка отсчёта для замера.
      *Проверка:* сводка сохранена, числа записаны в предложение.

## 2. Производство учится копить

- [ ] 2.1 Заменить в `tryTrain` возврат `passing(UnitUnaffordable)`
      на `waitOrPass` с той же причиной.
      *Проверка:* юнит-тест — при цене в пределах горизонта попытка
      возвращает `wait`, за пределами `pass`.
- [ ] 2.2 Обновить комментарий «Юниты дёшевы, копить незачем»: назвать,
      почему для гранатомётчика в десять базовых стоимостей это неверно.
      *Проверка:* комментарий объясняет причину, а не действие.
- [ ] 2.3 Проверить, что накопление на юнита не мешает сопровождению:
      при выбранном дальнем рубеже и пустом войске порядок трат
      по-прежнему начинается с производства.
      *Проверка:* существующие тесты сопровождения зелёные.

## 3. Список целей прокачки становится весами

- [ ] 3.1 Заменить в `PhaseProfile` поле `upgrades` со списка целей
      на словарь весов, по образцу `mix`.
      *Проверка:* типы собираются, оба профиля переведены без изменения
      смысла (прежний порядок выражен убывающими весами).
- [ ] 3.2 Заменить в `tryUpgrade` перебор целей на взвешенную
      жеребьёвку тем же генератором, каким выбирается тип юнита.
      *Проверка:* юнит-тест — цель с нулевым весом не выбирается
      никогда, цель с ненулевым выбирается.
- [ ] 3.3 Убедиться, что наблюдатель не трогает генератор: прогон
      с наблюдателем и без него даёт одинаковую контрольную сумму.
      *Проверка:* существующий тест на это зелёный.
- [ ] 3.4 Обновить эталон `profile.golden.test.ts`.
      *Проверка:* эталон отражает новую форму, тест зелёный.

## 4. Замер и следом — числа

- [ ] 4.1 Прогнать seed 3000–3023 и сравнить с линией из 1.3.
      *Проверка:* заказаны все типы с ненулевым весом; покупки есть
      по каждой названной цели; доход к концу матча выше, чем на пятой
      минуте.
- [ ] 4.2 Проверить страховочную величину: снятое с базы здоровье
      не упало.
      *Проверка:* величина не ниже линии из 1.3.
- [ ] 4.3 **Если упало — это ожидаемо.** Записать наблюдение и завести
      отдельное изменение на правку долей: механизм и числа чинятся
      порознь.
      *Проверка:* в изменении названы конкретные доли и то, чем они
      плохи, со ссылкой на замер.
