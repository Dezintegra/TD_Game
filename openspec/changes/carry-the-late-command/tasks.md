# Задачи

Каждая задача — отдельный коммит, отправляемый сразу. Порядок не
переставляется: правка сервера идёт **раньше** переноса, иначе перенос
на время внесёт фантом вместо просадки.

## 1. Сервер перестаёт съедать команду до начала матча

- [x] 1.1 `submit` в `packages/netplay/src/host.ts` отбрасывает команду
      только в фазе `finished`. В фазе `awaiting-players` команда
      проходит обычным путём через `clamp` и ложится в `pending`.
- [x] 1.2 Тест в `host.test.ts`: команда, отданная до подключения
      второго участника, оказывается в истории матча и в кадре одного
      из первых тактов.
- [x] 1.3 Тест там же: команда, отданная после завершения матча,
      в историю не попадает.

## 2. Предел переноса

- [x] 2.1 `COMMAND_CARRY_LIMIT_TICKS` в
      `packages/shared/src/constants.ts` с обоснованием обеих границ

## 3. Клиент переносит, а не забывает

- [x] 3.1 `forget` в `packages/netplay/src/guest.ts` разделяется
      на две части: уборку памяти контрольных сумм и улаживание
      очереди своих команд. Улаживание принимает число проигранных
      кадром своих команд, снимает столько же самых старых записей,
      остальные с тактов ниже `confirmed.tick` переставляет
      на `confirmed.tick` и выбрасывает просроченные.
- [x] 3.2 `drain` считает свои команды в кадре и передаёт их число
      в улаживание.
- [x] 3.3 Разбор `History` считает свои команды в проигранном отрезке
      и зовёт то же улаживание вместо прежнего удаления.

## 4. Проверки поведения

- [x] 4.1 Тест «опоздавшая команда не проседает в предсказании»:
      след числа юнитов в предсказанном мире не имеет провала.
      Без правки тест падает — это его смысл.
- [x] 4.2 Тест «перенесённая команда не удваивается»: после улаживания
      у стороны ровно один юнит, `pendingCount` вернулся к нулю.
- [x] 4.3 Тест «отказ ядра снимает команду с очереди»: заказ, на который
      не хватает энергии, приходит кадром и перестаёт применяться
      в предсказании.
- [x] 4.4 Тест «команда, которой сервер не получал, гаснет по сроку»:
      гость с подставной отправкой, кадры идут, команда не возвращается;
      через `COMMAND_CARRY_LIMIT_TICKS` она исчезает из предсказания.
- [x] 4.5 Тест «пачка не мигает»: десять заказов, доехавших двумя
      порциями на соседних тактах, дают непрерывные десять юнитов
      в предсказании.
