## Why

Влитая основа `card-dependencies` (PR #165 через PR #169, свежая main `9878558`) уже удерживает задачи до `closed`, освобождает квоты и пропускает готовые фичи мимо ожидающих прогонов. Но `closed` не доказывает нужный результат: карточку можно закрыть без вливания ожидаемого PR, в том числе после снятия предмета. Для случая 0235 → 0236 из журнала нужна проверяемая гарантия вливания конкретного предшественника, а не только окончания его имплементации.

## What Changes

- Дополнить существующий `dependsOn` необязательным `dependencyResults`: перечнем `{ taskId, kind: "merged-pr", pr }`, усиливающим выбранные зависимости требованием вливания конкретного PR в главную ветку репозитория конвейера.
- Сохранить обычное ожидание `closed` для старых карточек. Усиленная зависимость требует одновременно `closed`, совпадения ожидаемого PR с `links.pr` предшественника и подтверждения GitHub о вливании в настроенную главную ветку.
- Передать подтверждения в чистый сканер снимком; ошибки чтения и неполные сведения удерживают только зависимые задачи без сессий и расхода попыток.
- Сохранить метаданные при чтении, сохранении и создании карточек из `requests`; получать сведения о результате также для архивных карточек.

## Non-goals

- Повторная реализация `dependsOn`, новая колонка ожидания, изменение маршрутов и исходов этапов.
- Исход `premature` и его связь с зависимостями: отдельные задачи 0216 и 0219.
- Извлечение зависимостей из прозы или `links.related`, автоматическая правка существующих карточек доски.
- Универсальный язык условий, проверка качества кода, результатов арены, факта выкладки, ожидание PR до закрытия карточки или проверка отмены уже влитых изменений.
- Остановка живых процессов и отбрасывание готовых отчётов при изменении предусловия.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `card-dependencies`: необязательный ожидаемый результат зависимости и допуск только после его подтверждения; существующие требования изменяются полными MODIFIED, дополнительные гарантии источника сведений — ADDED.

## Impact

Реализация затронет обе схемы задач, `supervisor/lib/dependencies.mjs`, обмен карточками в `card.mjs`, `backlog-trello.mjs`, `requests.mjs`, сборку снимка в `bin/supervise.mjs` и `bin/cycle.mjs`, передачу доказательств в `scan.mjs`, узкие тесты и `manage/README.md`. Новый общий модуль чтения доказательств использует существующий исполнитель команд; зависимости пакетов не добавляются.

Отзывчивость игрового интерфейса и игровой сетевой трафик не меняются: клиент, сервер и симуляция не затронуты. Служебный трафик увеличивается не более чем на одно чтение GitHub для каждого уникального ожидаемого PR за снимок, только для закрытых предшественников задач, которым может понадобиться запуск. При отсутствии усиленных зависимостей новых запросов нет; Trello уже читает архивные карточки общим снимком.

## Пересечения и порядок

Основа `card-dependencies` уже архивирована в `openspec/specs/card-dependencies/spec.md`; зависимости порядка архивации нет. Решение владельца использовать её как базу соблюдено.

Открытые `backlog-in-trello`, `supervise-the-pipeline`, `outlive-the-supervisor`, `batch-deploy`, `hold-uncovered-stages`, `count-only-real-launches`, `support-both-agents` и `reconcile-codex-token-usage` пересекаются файлами обмена и планирования; их действующие правила сохраняются, дельт поверх них нет. При реализации сверить их свежие правки. Изменения 0216/0219 в предоставленной описи касаются будущего возврата преждевременной задачи; наш контракт не добавляет такого исхода и не требует их архивации первым.
