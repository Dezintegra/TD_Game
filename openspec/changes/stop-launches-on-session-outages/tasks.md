## Порядок исполнения

Каждый пункт — один самостоятельно проверяемый коммит вместе с отметкой в этом файле. Перед реализацией освежить назначенное дерево командами `git -C <дерево> fetch origin` и `git -C <дерево> merge origin/main` по правилам этапа; изменения вне задачи не включать. Команды Git для каждого пункта: `git -C <дерево> add -- <явные пути>`, `git -C <дерево> commit -m "<заголовок>" -m "<обоснование>"`, `git -C <дерево> push`. Выполнять их отдельными вызовами.

Формы `PowerShell(npx vitest:*)`, `PowerShell(npx eslint:*)`, `PowerShell(npx prettier:*)` и `PowerShell(git -C:*)` сверены с `supervisor/config/stage-settings.json`; тестам обязательно передавать `--root supervisor`. Эти проверки предназначены для имплементации, не проработки. Живые запросы к API и запуск настоящих этапов не нужны: процесс, часы, проба и операции паузы внедряются в стенд. Арену заказывать не требуется, игровых изменений нет.
