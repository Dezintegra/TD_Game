# Задачи

## 1. Расчёт рывка

- [x] 1.1 Завести чистую функцию оценки волны: на входе мир, сторона,
      тип юнита, число машин и вероятный путь; на выходе — сколько
      снимется с базы.
      *Проверка:* функция проверяется прямыми вызовами, без прогона матча.
- [x] 1.2 Считать потери в пути по вражескому урону вдоль маршрута,
      а не по каждому юниту отдельно: башня стреляет по одному за раз,
      и урон вычитается из общего здоровья волны.
      *Проверка:* юнит-тест — волна вдвое большая теряет ту же величину
      здоровья, а не вдвое большую.
- [x] 1.3 Ограничить время у базы горизонтом планирования, когда обороны
      нет вовсе.
      *Проверка:* тест — при пустой обороне расчёт конечен.
- [x] 1.4 Выбор типа волны: гранатомётчик при прикрытом пути, штурмовик
      при чистом, снайпер — никогда.
      *Проверка:* три случая проходят.

## 2. Залп

- [x] 2.1 Разрешить рывку заказывать волну целиком за одно решение,
      в обход правила «одна покупка за решение».
      *Проверка:* тест — при открытых воротах в одном решении больше
      одной команды заказа.
- [x] 2.2 Ограничить залп очередью производства и потолком численности,
      не полагаясь на отказы ядра.
      *Проверка:* число команд не превышает свободного места в очереди.
- [x] 2.3 Записать рывок в наблюдение отдельным признаком.
      *Проверка:* признак доезжает до таблицы решений.

      *Проверка:* таблица приложена к изменению.
