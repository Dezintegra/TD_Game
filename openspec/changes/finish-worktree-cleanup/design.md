## Context

Git может снять регистрацию дерева раньше удаления каталога. Ошибка второго вызова не доказывает отсутствие файлов.

## Goals / Non-Goals

Завершать уборку фактически, сохраняя повторяемость и границы удаления. Не менять проверки влитости и владельца задачи.

## Decisions

Отдельный файловый помощник проверяет, что цель — прямой дочерний каталог штатного .claude/worktrees и его реальные родители не перенаправлены ссылками. Сначала вызывается Git. Только подтверждённое отсутствие регистрации разрешает дочистку через Node fs.rmSync с ограниченными повторами. Любая иная ошибка сохраняет состояние для следующего оборота. После удаления проверяется фактическое отсутствие цели. Проверки используют временные каталоги и подставной ответ Git; отдельно проверяется ссылка на внешний каталог.

## Risks / Trade-offs

Занятые файлы могут остаться до следующего оборота: помощник возвращает ошибку, реестр сохраняется. Нештатные пути отклоняются до удаления. Ссылки внутри дерева удаляются как ссылки, без обхода их целей.

## Migration Plan

Узкие тесты помощника и уборки, CI, слияние и штатное самообновление. Работающая сессия не прерывается.
