## Why

После успешной выкладки Git на Windows снял регистрацию десяти деревьев, но оставил непустые каталоги. Следующий оборот считал ответ «not a working tree» успехом и терял запись реестра вместе с возможностью дочистить остатки.

## What Changes

Уборка подтверждает отсутствие каталога. Если регистрация уже снята, удаляет оставшийся каталог только внутри штатного каталога деревьев, с проверкой пути и отсутствия ссылки на другой каталог. При отказе сохраняет запись реестра для повтора.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет.

## Почему дельты нет

Восстанавливается существующее требование cleanup: запись реестра снимается только после удаления всех следов.

## Non-goals

Не менять решение о влитости PR, не трогать работающие деревья, не менять этапы и квоты.

## Impact

Переходник удаления дерева и узкие проверки файловой системы. Игровые кадры и сетевой трафик не затронуты.
