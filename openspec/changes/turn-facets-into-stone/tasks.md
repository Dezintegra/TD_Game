# Задачи

## 1. Поле высот

- [x] 1.1 Вынести в чистые функции поле высот: сглаживание высот клеток
      в непрерывную поверхность и подножие у границы каменной области.
      Расстояние до края считать по клеткам-соседям, а не размытием —
      размытие даёт волнистую границу, не совпадающую с клеткой.
      Сделано в новом `relief.ts`, `rocks.ts` пока не тронут.
      Проверка: `relief.test.ts` — поверхность не выходит за клетку;
      на границе с проходимой клеткой высота нулевая; подножие занимает
      меньше половины клетки; внутри массива соседние клетки стыкуются
      непрерывно и высоту на общей границе не теряют. Восемнадцать
      сценариев зелёные.
      Поймано тестом: в глубине массива `edgeDistance` возвращала
      заглушку 0,5 — меньше ширины подножия, отчего вся внутренность
      крупного массива просаживалась по высоте на десятую часть.
      Верная нижняя оценка там — единица.
- [x] 1.2 Завести дробный шум как отдельную функцию, пригодную и для
      процессора, и для переноса в шейдер. Хеш взят общий, из `noise.ts`.
      Проверка: одна и та же точка даёт одно и то же значение; значения
      лежат в [0, 1) при любом числе октав; соседние точки близки
      (шум гладкий, в отличие от потока из `noise.ts`); разные зёрна
      дают разный рисунок.
- [x] 1.3 Отделить фактуру от геометрии: возмущение нормали считается
      своей функцией и в поле высот не участвует.
      Проверка: в поле высот нет подробностей мельче шага отрисовки
      (уклон на шаге 1/22 нигде не превышает четырёх) — мерить надо
      именно это, а не абстрактную гладкость: губку на пробе дал
      не «сильный шум вообще», а подробности короче расстояния между
      выборками. Плюс: фактура разворачивает нормаль там, где
      поверхность ровная.

## 2. Шейдер и запекание

- [ ] 2.1 Написать фрагментный шейдер освещения поверхности: нормаль
      из уклона поля высот плюс возмущение фактуры, основной источник
      с прежними `AMBIENT_LIGHT` и вектором из `prism.ts`.
      Проверка: горизонтальная площадка скалы и верхняя грань соседней
      постройки дают одну и ту же освещённость.
- [ ] 2.2 Завести `relief.ts`: построение текстуры одной скальной клетки
      через `RenderTexture`, окном по глобальному полю высот.
      Проверка: две соседние клетки, построенные по отдельности,
      стыкуются без шва.
- [ ] 2.3 Освобождение текстур: рельеф уходит вместе с матчем, палитра
      сменилась — старые текстуры уничтожаются.
      Проверка: после смены палитры и после выхода из матча счётчик
      живых текстур возвращается к исходному.

## 3. Встраивание в сцену без потери перекрытия

- [ ] 3.1 Заменить в `terrain.ts` построение граней скал на спрайты
      рельефа, разложенные по тем же диагональным слоям.
      Проверка: юнит за скалой перекрыт ею, юнит перед скалой — нет;
      сценарий добавляется в `terrain.test.ts`.
- [ ] 3.2 Убрать из `scene.ts` полосы `Graphics` под скалы, оставить
      их под сетку земли.
      Проверка: сетка на проходимых клетках рисуется по-прежнему,
      под скалами её нет.
- [ ] 3.3 Ленивое построение: спрайт клетки строится при первом её
      появлении в поле зрения.
      Проверка: сразу после старта построено меньше клеток, чем всего
      скальных; после обхода камерой всей карты — все.

## 4. Фактура, затенение, воздух

- [ ] 4.1 Прослойки породы в цвете поверхности.
      Проверка: два соседних участка одного наклона различаются
      по освещённости.
- [ ] 4.2 Затенение в вогнутостях: точка ниже своей округи темнее точки
      того же наклона на открытом склоне.
      Проверка: сценарий из спецификации.
- [ ] 4.3 Второй источник — холодный свет неба, тем больший, чем ближе
      поверхность к горизонтальной.
      Проверка: вклад света неба смещён в холодную часть спектра
      относительно основного источника.
- [ ] 4.4 Воздушная дымка по удалению от зрителя.
      Проверка: из двух одинаково освещённых точек дальняя приглушена
      сильнее.

## 5. Снег

- [ ] 5.1 Добавить к условию по мировой отметке условие по крутизне:
      выше линии снег тем плотнее, чем положе поверхность.
      Проверка: выше линии на пологом участке снег есть, на отвесном
      его нет; ниже линии снега нет нигде.
- [ ] 5.2 Убедиться, что граница снега у двух заснеженных клеток разной
      высоты проходит на одной мировой высоте.
      Проверка: прежний сценарий `rock-appearance` остаётся зелёным.

## 6. Палитра и уход обводки

- [ ] 6.1 Убрать `stroke` по рёбрам и токен `--td-rock-edge` из палитры
      скал; добавить цвет света неба.
      Проверка: соседние скалы различимы без обводки — освещённость
      на их смежных скатах различается.
- [ ] 6.2 Зеленоватый налёт на пологих участках оставить, ограничить
      разброс цвета породы по приглушённости: насыщенность не выше 35%,
      яркость не выше 65%.
      Проверка: тест перебирает весь разброс, а не одну точку, и требует
      от каждого цвета быть заметно менее насыщенным и менее ярким,
      чем цвет любой из сторон; налёт проверку проходит.
