# Задачи

Задачи выстроены так, чтобы преследование можно было отрезать.
Разделы 1–3 закрывают огонь на ходу и два режима из трёх и оставляют
игру в связном состоянии. Останавливаться, если работа встанет, надо
после раздела 3, а не посреди четвёртого.

## 2. Огонь на ходу

## 3. Режимы «Прорыв» и «Бой»

- [x] 3.1 В `moveUnits` (`packages/sim/src/movement.ts`) сделать
      проверку встречного противника зависящей от режима. Остановки
      у назначенной цели и у ломаемой преграды не трогать ни в одном
      режиме.
      _Проверка:_ тесты обоих режимов.
- [x] 3.2 Тест: гранатомётчик по-прежнему останавливается у назначенной
      цели вне радиуса башни — в обоих режимах. Это единственное, ради
      чего он существует, и режим не должен на это влиять.
      _Проверка:_ тест зелёный в обоих режимах.
- [x] 3.3 Тест: юнит останавливается и ломает перегородившую путь
      постройку в обоих режимах.
      _Проверка:_ урон постройке наносится.
- [x] 3.4 Переключатель на три положения в `ActionBar.tsx` рядом
      с выбором цели, текущий режим виден всегда. Горячие клавиши
      Z, X, C — свободны, лежат подряд и сами выглядят переключателем.
      _Проверка:_ нажатие меняет отметку в том же кадре; занятые
      клавиши (WASD, QER, 123, F) не задеты.
- [x] 3.5 Выбор режима у противника: вывести из позиции

      _Проверка:_ за сотню тиков без смены позиции уходит не больше
      одной команды.
- [x] 3.6 Обновить эталон в `determinism.golden.test.ts`: поведение
      по умолчанию стало другим.
      _Проверка:_ тест зелёный с новым числом.
- [ ] 3.7 Замер на арене: «Прорыв» против «Боя». Урон по базе за матч,
      доля войска, дошедшего до цели, потери, длительность матча.
      _Проверка:_ таблица приложена.
- [x] 3.8 Остановка на стреляющей постройке наравне с живым противником.

## 4. Преследование

- [ ] 4.1 Сделать `nearestHostile` в `combat.ts` и выразить через него
      существующий `hasHostileInSight`. Второй похожий обход рядом
      не писать: два обхода с почти одинаковыми условиями разъедутся
      при первой правке.
      _Проверка:_ поведение «Боя» не изменилось — прежние тесты зелёные.
- [ ] 4.2 Два поля в состоянии юнита: за кем гонимся и клетка начала
      погони. Оба — в `world.ts`, `working.ts` и `checksum.ts`.
      _Проверка:_ сумма различается для юнитов с разной жертвой.
- [ ] 4.3 Предел преследования в `balance.ts` с выводом в комментарии:
      сколько юнит проходит за три перезарядки. Отправное значение —
      около шести клеток.
      _Проверка:_ величина выражена через существующие, а не числом.
- [ ] 4.4 Снимок положений на начало тика рядом с уже существующим
      индексом в `step.ts`. И выбор жертвы, и движение к ней берут
      положения оттуда, иначе исход зависит от порядка обхода массива.
      _Проверка:_ тест — перестановка юнитов местами в массиве
      не меняет исход.
- [ ] 4.5 Логика погони в `moveUnits`: взять жертву, идти к ней прямо,
      бросить при её гибели, при исчезновении или при выходе за предел,
      после чего вернуться к полю потока.
      _Проверка:_ четыре теста по числу способов закончить погоню.
- [ ] 4.6 Генералы жертвами не становятся.
      _Проверка:_ тест — генерал в радиусе погоню не начинает.
- [ ] 4.7 Тест приманки: быстрый юнит проезжает вдоль строя и уходит
      через карту; ни один преследователь не уходит дальше предела
      от места, где начал. Это главный тест раздела.
      _Проверка:_ тест зелёный; при снятии предела падает.
- [ ] 4.8 Тест: преследователь стреляет по лестнице приоритетов,
      а не по жертве. Погоня управляет движением, а не стволом.
      _Проверка:_ выстрел приходится по генералу, движение продолжается
      за прежней жертвой.
- [ ] 4.9 Тест застревания: жертва за стеной, обойти нельзя. Юнит
      не должен зависнуть навсегда — расстояние не сокращается, жертва
      уходит, срабатывает предел.
      _Проверка:_ юнит возвращается к цели за конечное число тиков.
- [ ] 4.10 Замер погони на арене: доля юнитов, вернувшихся к цели,
      и разброс юнитов по карте.
      _Проверка:_ таблица приложена; малая доля вернувшихся означает,
      что предел велик.
