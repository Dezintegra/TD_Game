# add-attack-stances

Игрок получает второе решение о войске после выбора цели: что юниты
делают при встрече с противником.

| Режим                     | Поведение                                           |
| ------------------------- | --------------------------------------------------- |
| **Прорыв** (по умолчанию) | Не останавливается, идёт к цели, стреляя на ходу    |
| **Бой**                   | Останавливается и бьётся до конца, но не преследует |
| **Преследование**         | Гонится за противником, потом возвращается к цели   |

Сейчас поведение одно и зашито в ядро: юнит стоит, пока в радиусе есть
живой противник. Из-за этого «доехать до цели любой ценой» неисполнимо
(армия встаёт о первый заслон), «добить отступающего» тоже
(отошёл на клетку — потерял интерес), а взаимный расстрел на ходу
объявлен в замысле ошибкой, хотя ею не является.

Тезис замысла 5.4 («две армии проходили друг сквозь друга... не тактика,
а отсутствие события») отменяется прямым решением. Прежнее поведение
не пропадает — становится режимом «Бой».

Попутно записывается правило, которое работает, но нигде не заявлено:
**движущийся юнит стреляет**, во всех режимах.

**Меняется эталон детерминизма:** поведение по умолчанию стало другим.

**Знать заранее:**

- Преследование «до уничтожения» буквально понимать нельзя: вражеский
  генерал быстрее любого юнита, приоритетнее всех целей и возрождается
  бесплатно — один проезд вдоль строя увёл бы за собой всю армию.
  Предел обязателен, за генералом не гонятся вовсе.
- «Прорыв» по умолчанию снова открывает дыру со скоплением юнитов
  у цели (замысел, 11). Это принято, а не упущено; замер обязан
  включать урон по базе.
- Задачи выстроены так, чтобы преследование можно было отрезать:
  оно стоит примерно столько же, сколько два первых режима вместе.

**Порядок:** применять **после** `slow-down-construction` и замерять
отдельно. То ослабляет оборону, это усиливает наступление; вместе
они неразличимы в замере.
