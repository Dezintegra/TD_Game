## ADDED Requirements

### Requirement: Единый снимок выкладки

Супервизор MUST до запуска deploy подготовить отдельное detached-дерево
закреплённого коммита настроенной главной ветки без изменения дерева задачи.
Исполнитель MUST использовать этот коммит и дерево для замера и выкладки.

#### Scenario: Историческая ветка конфликтует с main

- **WHEN** старая ветка задачи расходится с main
- **THEN** создаётся чистый снимок main без merge, reset или удаления файлов задачи

### Requirement: Сохранение снимка при продолжении

Супервизор MUST сохранить путь и ревизию до spawn и повторно использовать их.
Неверный, чужой или грязный снимок MUST остановить подготовку без очистки.

#### Scenario: Main продвинулся

- **WHEN** deploy возобновляется после новых коммитов main
- **THEN** используется прежний сохранённый хеш

#### Scenario: Старое продолжение без снимка

- **WHEN** прерванный deploy не имеет сохранённого снимка
- **THEN** новый исполнитель не запускается и причина явно сообщается

#### Scenario: Дерево изменено

- **WHEN** сохранённый снимок грязный или имеет иной HEAD
- **THEN** подготовка завершается ошибкой и содержимое не изменяется
