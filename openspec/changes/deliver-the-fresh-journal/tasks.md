# Задачи

Каждый пункт — отдельный коммит, собирающийся и проверяемый сам по себе.
Проверки узкие и местные; полный набор гоняет CI (правило 6 в `CLAUDE.md`).

**Оговорка о проверке.** После составления этого плана тесты конвейера
включили в CI. Каждый шаг сначала проверяется местным узким прогоном чистых
функций, а итог — проверками того же коммита PR.

Порядок не случаен. Сперва появляется разбор журнала на записи, которым
пользуются оба следующих шага; затем выдержка; затем подключение к промпту;
и только потом отдельный раздел вердикта. Каждый промежуточный шаг оставляет
конвейер работоспособным: новые функции никем не зовутся, пока до них
не дойдёт черёд.

## 1. Журнал разбирается на записи

- [ ] `supervisor/lib/stage-prompt.mjs`: завести `splitJournalEntries(text)`,
      возвращающую записи по порядку. Границей считать строку, целиком
      равную `## …` либо `**… → …**` — со стрелкой обязательно. Текст
      до первой границы (заголовок журнала) возвращать первым куском.
- [ ] Границ не нашлось — вернуть весь текст одним куском. Это признак
      журнала старого образца, и разбирать там нечего.
- [ ] Тесты в `supervisor/lib/stage-prompt.test.mjs`: журнал доски
      (`**design → audit**`) и файловый (`## 2026-09-02 · design → audit`)
      разбираются одинаково; жирные подзаголовки тела — `**Решения:**`,
      `**Отказано в действиях:**` — границами **не** считаются; склейка
      разобранного даёт исходный текст без потерь.

**Проверка:** `npx vitest run --root supervisor lib/stage-prompt.test.mjs`
зелёный. После этого коммита открыть черновой pull request — до его
появления пуши в ветку не запускают проверок CI вовсе.

## 2. Выдержка набирается целыми записями с конца

- [ ] `supervisor/lib/stage-prompt.mjs`: заменить построчную реализацию
      `clipJournal(text, limit)` набором целых записей.
      Хвост — записи с конца, пока укладываются; последняя запись входит
      всегда, даже одна переросшая предел; голова добавляется, если после
      хвоста осталось место; между ними пометка с числом пропущенных знаков
      **и** числом пропущенных записей.
- [ ] Последнюю запись не резать даже при превышении четырёхкратного
      предела: исходное требование требует её целиком. Размер явно виден
      по длине передаваемого журнала; ограничение на остальные записи остаётся.
- [ ] Разбор не дал границ — вернуться к `clipMiddle` по знакам.
- [ ] Тесты там же: журнал короче предела приходит целиком и без пометки;
      длинный отдаёт последнюю запись дословно; последняя запись длиннее
      предела и четырёхкратного предела всё равно цела; пометка называет
      оба числа.

**Проверка:** `npx vitest run --root supervisor lib/stage-prompt.test.mjs`
зелёный.

**Проверка:** `npx vitest run --root supervisor lib/stage-prompt.test.mjs`
