## 5. Правила исполнения всех пунктов

Каждый пункт — самостоятельный собирающийся коммит, отправляемый сразу. К явным рабочим путям каждого пункта обязательно добавляется только его отметка выполнения в `openspec/changes/adapt-rock-density-to-camera/tasks.md`. Стейджить фактически изменённые пути явным списком; не использовать добавление всего дерева. Перед коммитом проверить имена и содержание через `git -C <дерево> diff --cached --name-only` и `git -C <дерево> diff --cached`; после — `git -C <дерево> show --stat HEAD` и `git -C <дерево> show HEAD`. Команды выполнять раздельно, отправка — `git -C <дерево> push`. Допуск tasks.md не разрешает несвязанные правки внутри него.

Перед узкими проверками зависимости собственного дерева готовятся штатным этапом implement. Полный verify, сборка и матчевые тесты остаются CI; ожидание CI в пункты не входит. Замер кадров выполняется только перед выкладкой штатным механизмом, отдельная заявка и пункт запуска perf не нужны. Игровые правила не меняются, арена не заказывается. Архивация и правка Purpose выполняются позднее уполномоченным этапом/человеком в порядке proposal; пунктами реализации они не являются.
