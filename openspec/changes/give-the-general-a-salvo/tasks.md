# Задачи

## 1. Правила: скорострельность

- [x] 1.1 Сократить `GENERAL_STATS.cooldownTicks` до
      `Math.round(BASE_COOLDOWN_TICKS / 4)` с объяснением, почему восемь,
      а не семь и не семь с половиной.
      Проверка: `balance.test.ts` — перезарядка вчетверо меньше базовой
      с точностью до округления.
- [x] 1.2 Заменить проверку дуэли в `balance.test.ts`: одну башню генерал
      берёт и остаётся жив, на паре разменивается один к одному,
      трёх не переживает.
      Проверка: три утверждения на трёх числах, посчитанных из таблицы,
      а не вписанных руками.
- [x] 1.3 Убедиться, что охота за юнитами по-прежнему невыгоднее
      пассивного дохода на базовых числах.
      Проверка: прежний тест `balance.test.ts` зелёный без правки.

## 2. Правила: борт ракеты

- [x] 2.1 Завести `ShotSide` в `balance.ts`: `Left = -1`, `Centre = 0`,
      `Right = 1`, со значениями-множителями и объяснением, почему так.
      Проверка: `balance.test.ts` — значения бортов противоположны
      по знаку, у центра ноль.
- [x] 2.2 Добавить `nextMissileSide` в `GeneralState`, в `WorkingGeneral`,
      в обе стороны переноса (`toWorking`/`fromWorking`) и в создание
      мира. Начальное значение одинаково у обоих игроков.
      Проверка: `combat.test.ts` — у обоих генералов один и тот же борт
      на первом тике (карта симметрична поворотом).
- [x] 2.3 Добавить `side` в `ShotState` и в `recordShot`; всем стрелкам,
      кроме генерала, — `ShotSide.Centre`.
      Проверка: `combat.test.ts` — след выстрела юнита и башни идёт
      по оси.
- [x] 2.4 Переключать борт в `fireGeneral` на каждом выстреле и класть
      использованный борт в след.
      Проверка: `combat.test.ts` — два подряд выстрела генерала дают
      следы с противоположными бортами; промолчавший генерал борта
      не тратит.
- [x] 2.5 Оставить борт вне контрольной суммы, пометив исключение
      комментарием в `checksum.ts`.
      Проверка: `combat.test.ts` — миры, отличающиеся только бортом,
      дают одну сумму (рядом с такой же проверкой про вид оружия).

## 4. Клиент: ракета уходит с борта

- [x] 4.1 Вынести края пилона в именованные величины и отдать наружу
      вылет подвески — внешний край.
      Проверка: чтением. Отдельного теста нет намеренно: форма пилона
      и вылет подвески берут ОДНО И ТО ЖЕ число, стоящее строкой выше,
      и тест здесь пересказал бы присваивание. Расхождение двух копий
      он бы поймал, а копии тут нет.
- [x] 4.2 Сместить точку старта ракеты поперёк линии огня на вылет

      из разных точек, симметричных относительно машины; выстрел
      с `Centre` стартует ровно над стрелком.
- [x] 4.3 Убедиться, что вспышка у ствола ушла на борт вместе с ракетой.
      Проверка: `shots.test.ts` — свет у старта совпадает с точкой
      старта, а не с осью машины.

## 6. Приёмка

- [x] 6.1 `pnpm verify` — линт, типы, тесты, сборка.
      Типы, сборка и тесты зелёные целиком; линт по этому изменению
      чистый (`eslint packages/shared packages/sim packages/ai apps/client`),
      но `pnpm lint` на всём дереве падает по чужой причине —
      незакоммиченный `scripts/deploy.mjs` из работы над развёртыванием
      не объявляет `process` и `console`. Прежняя помеха (типы в
      `apps/client/src/audio`) снята: работа над звуком закоммичена.
      Проверять заново перед коммитом.
- [x] 6.3 Восстановить перезарядку после замера A/B.
      Значение `GENERAL_STATS.cooldownTicks` было временно возвращено
      к `BASE_COOLDOWN_TICKS` с пометкой «ЗАМЕР A/B, вернуть на /4»
      и таким и осталось: обоснование на восемь тиков стояло
      комментарием, а число рядом с ним было старым. Тесты на дуэль,
      на «вчетверо чаще» и на «два следа в воздухе» при этом висели
      красными. Возвращено на `Math.round(BASE_COOLDOWN_TICKS / 4)`.
- [x] 6.2 Матч из симуляции, отрисованный боевым кодом: генерал бьёт
      очередью, ракеты уходят то с левого пилона, то с правого, и на
      девятом тике вторая уходит ровно тогда, когда первая приходит
      в цель, — в воздухе две сразу.
