## Why
Автономные этапы Codex отклоняют даже git status; супервизор при этом печатает нулевое число отказов. Проверка ответа модели без инструментов ошибочно воспринималась как готовность среды.

## What Changes
- Явная настройка Windows sandbox при изолированном запуске Codex.
- Проверка выполнения безвредной команды до выдачи задач, с явным отказом запуска при неработающей среде.
- Учёт declined-событий и остановка выдачи новых задач при отказе политики.
- Исправление инструкции диагностики и наблюдения.

## Capabilities
### New Capabilities
- codex-startup-readiness: проверенная возможность запуска команд и видимость отказов.
### Modified Capabilities
Нет.

## Impact
Только supervisor и документация; отзывчивость игры и игровой сетевой трафик не меняются. Проба Codex расходует небольшое число токенов при старте.

## Non-goals
Не отключать sandbox, не обходить политики администратора, не менять игровые задачи вручную и не заменять авторизацию ChatGPT API-ключом.
