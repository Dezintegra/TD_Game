## Точная граница

Назначенный конечный путь:
`C:/src/dezintegra/TD_Game/.matchlog/refresh-source-deliveries/0372/<packageSha256>/`.

Действующий профиль этой сессии задаёт `sandbox_mode=workspace-write`,
`approval_policy=never`. Его проектные writable roots:

- `C:/src/dezintegra/TD_Game/.claude/worktrees/0372-realizovat-istochnik-prichinnoy-korrelya`;
- `C:/src/dezintegra/TD_Game/.git`;
- `C:/src/dezintegra/TD_Game/.git/worktrees/0372-realizovat-istochnik-prichinnoy-korrelya`;
- `C:/src/dezintegra/TD_Game/.perf-lock`;
- `C:/src/dezintegra/TD_Game/.perf-log.jsonl`.

Ни один не включает конечное хранилище. Правило самого design прямо требует
в таком случае сохранить ограничение и запрещает эскалацию либо запись через
Git/иной процесс/другое хранилище. Внешний Windows-хозяин не предоставлен этой
сессии как исполняемый инструмент. Наличие сетевого доступа и разрешение первого
допуска не расширяют эти пути. Попытка записи в запрещённый каталог намеренно
не выполнялась: факт здесь — точный запрещающий профиль, а не выдуманный EACCES.
`deliver`/`verify-delivery` не запускались; receipt успешной передачи отсутствует.

`schannel: AcquireCredentialsHandle failed: SEC_E_NO_CREDENTIALS (0x8009030E)`.
Тот же pinned source получен официальным GitHub API. TLS backend, ACL, profile

безопасного разбора PAX источник получен. Ошибка первоначального quoting `gh --jq`

дублирующие заявки не создаются. Совпадение причин остальных падений не доказано.

настройки ignore не менялись. CI #287 при однократном чтении ещё pending;
его зелень не заявляется, ожидания здесь нет.

## Неисполненный объём и следующий маршрут

**Не созданы** Rust patch, schema/reader, build driver/recipe, CLI и оба helper,
build/reproduce receipts, производственные отрицательные и mutation controls,
полный source-coverage review, package index и delivery receipt. BuildId и
packageSha256 отсутствуют; их нельзя заменить source/receipt hash. Пункты
2.1–5.2 и перенос из исходного 6.1 не выполнены. Подтверждённая граница передачи
использована как предусмотренный конечный альтернативный результат, а не как
заявление, будто вся оставшаяся разработка технически невозможна.

Ответственный за разрешённый внешний перенос — штатный Windows-хозяин,
названный design Decisions 6. Доступный способ после подготовки полного пакета:
копирование по package index в точный конечный каталог под обычным разрешённым
контекстом хозяина, затем независимое чтение всех bytes/SHA-256/размеров с UTC.
Пока пакета нет, одной операции copy недостаточно: сначала требуется завершить
перечисленную разработку в назначенной разрешённой области и проверки первого
допуска. Ни установка runtime, ни ACL/profile изменения этим не разрешены.

Материалы возвращаются существующей 0370 для нового анализа пригодности
альтернативного результата. Её запуск/collector не требуются для закрытия
этого этапа 0372. Новая обратная зависимость, дубликат карточки и второй допуск
не создаются. Нельзя автоматически считать выполненной причинную предпосылку,
снять инцидент 0366 или объявить sourceAvailable по этому документу.
