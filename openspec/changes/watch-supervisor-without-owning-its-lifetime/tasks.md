## Общие условия

Каждый пункт ниже — отдельный коммит до двух часов с немедленной отправкой. Рабочий каталог — назначенное дерево. `<дерево>` в командах означает его абсолютный путь. Перед каждым коммитом отметить только выполненный пункт в этом tasks.md; этот путь разрешён вместе с рабочими файлами каждого пункта.

Добавлять файлы явным перечнем через `git -C <дерево> add -- <перечень путей пункта> openspec/changes/watch-supervisor-without-owning-its-lifetime/tasks.md`. Сверять имена и содержание `git -C <дерево> diff --cached --name-only` и `git -C <дерево> diff --cached`, после коммита — `git -C <дерево> show --stat --oneline HEAD` и `git -C <дерево> show --format=fuller HEAD`. Допуск пути не разрешает посторонние правки внутри файла. Временные данные `.matchlog/watch-supervisor-tests/` в индекс и коммиты не включать. Отправлять `git -C <дерево> push`; отсутствие хвоста подтверждать `git -C <дерево> rev-list --left-right --count '@{u}...HEAD'` (0 0).

Локально только названные узкие проверки; полный набор остаётся CI. Команды сверены с `supervisor/config/stage-settings.json`: `PowerShell(git -C:*)`, `PowerShell(npx vitest:*)`, `PowerShell(npx eslint:*)`, `PowerShell(npx prettier:*)`, `PowerShell(openspec:*)`. Боевой пускатель, `--stop` и живой супервизор не запускать: поведение проверяется внедрёнными эффектами и безопасными фикстурами. Не менять доску, работающий процесс или планировщик. Ожидание CI не является пунктом реализации.
