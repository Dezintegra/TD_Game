# Шаги реализации

Каждый шаг — отдельный коммит, отправляемый сразу.

## 1. Инструмент переезжает в `supervisor/`

- [ ] `git mv plugins/pipeline supervisor`
- [ ] умолчания `skillsDir` и `stageSettings` теряют приставку каталога
      и становятся `skills` и `config/stage-settings.json`
- [ ] `stageCommand` получает каталог инструмента доводом и разрешает
      от него свои пути; абсолютный путь берётся как есть
- [ ] `supervise.mjs`, `cycle.mjs`, `board*.mjs` знают свой каталог
      и передают его дальше
- [ ] упоминания старого пути внутри инструмента исправлены:
      `config/stage-settings.json`, `skills/*.md`, `README.md`
- [ ] упоминания снаружи исправлены: `CLAUDE.md`, `manage/README.md`,
      скрипт `test:pipeline` в корневом `package.json`
- [ ] `vitest.config.ts` описывает новый корень

**Проверка:** `npx vitest run --root supervisor` зелёный; `node
supervisor/bin/cycle.mjs` печатает решение и не падает; поиск по
репозиторию не находит `plugins/pipeline` нигде, кроме архивных
документов OpenSpec.

## 2. У инструмента появляется своя упаковка

- [ ] `supervisor/package.json`: имя, `type: module`, точка входа,
      требование к версии Node, сценарии запуска — без зависимостей
- [ ] `supervisor/pipeline.config.example.json` — образец настройки
      с пояснением каждого значения
- [ ] `supervisor/.env.example` — переменные доступа к доске
- [ ] `.env` ищется рядом с инструментом, а затем в корне проекта

**Проверка:** `npx vitest run --root supervisor` зелёный; каталог,
скопированный во временное место вместе с образцами, содержит всё, что
названо в руководстве.

## 3. Этап отдаёт вывод потоком событий

- [ ] настройка `stageOutputFormat` со значениями `stream-json`
      (умолчание) и `json`
- [ ] `stageCommand` добавляет `--verbose` при потоковом формате
- [ ] `parseEnvelope` разбирает NDJSON, берёт последнее событие
      `type === 'result'`, снимает метку порядка байтов и по-прежнему
      понимает однократный ответ
- [ ] `startStage` разбирает приходящие строки и отдаёт события наружу
      доводом `onEvent`, не теряя вывод целиком для журнала этапа
- [ ] тесты: NDJSON с отчётом, NDJSON без отчёта, однократный ответ,
      метка порядка байтов, событие с обрывом строки на границе куска

**Проверка:** `npx vitest run --root supervisor` зелёный.

## 4. Супервизор рассказывает о работе в консоль

- [ ] `lib/console.mjs`: строка с отметкой времени и тегом, полоса даты
      при смене суток, цвет только для терминала, выжимка доводов
      средства, выжимка текста ответа
- [ ] `supervisor.mjs` переводит события этапа в строки консоли
      и считает ходы и последнее действие для пульса
- [ ] пульс раз в `pulseSeconds` по каждому живому этапу
- [ ] `supervise.mjs`: стартовый блок, начало и исход оборота, время
      следующего оборота, взятие задачи, завершение этапа
- [ ] ключ `--quiet` возвращает прежнюю немоту; `--verbose` сохраняется
      как признание совместимости и ничего не меняет
- [ ] тесты `lib/console.mjs`: формат строки, смена суток, отсутствие
      цвета вне терминала, урезание длинных доводов

**Проверка:** `npx vitest run --root supervisor` зелёный; `node
supervisor/bin/supervise.mjs --dry-run` печатает стартовый блок и оборот.

## 5. Окружение проверяется при запуске

- [ ] `lib/environment.mjs`: перечень проверок, каждая возвращает
      «нашлось — не нашлось — что делать»
- [ ] запуск внешних программ приходит доводом, чтобы проверка
      проверялась без настоящих запусков
- [ ] отсутствие каталога правил этапов останавливает запуск, прочее —
      предупреждение
- [ ] тесты: полное окружение, нет `gh`, нет доступа к доске, нет правил
      этапов

**Проверка:** `npx vitest run --root supervisor` зелёный; запуск
на машине без `gh` в пути печатает предупреждение и продолжает.

## 6. Руководство по установке на чистую машину

- [ ] `supervisor/README.md`: что это, что нужно на машине, установка
      по шагам, настройка, сторож, что печатается в консоль и как это
      читать, чего инструмент не делает
- [ ] `CLAUDE.md` и `manage/README.md` ссылаются на новый путь

**Проверка:** прочитать руководство и пройти по нему на чистом каталоге,
не заглядывая в код.
