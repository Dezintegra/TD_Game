# Задачи

- [x] 1.1 `packages/protocol`: предел длины пароля, причины отказа
      `WrongPassword` и `BadPassword`, признак `locked` у строки списка.
      Раскладка байтов игрового кадра не меняется, `PROTOCOL_VERSION`
      остаётся прежним — комнаты ходят JSON.
- [x] 1.2 `apps/server/lobbies.ts`: замок комнаты (соль и хеш), годность
      пароля, сверка постоянного времени, порядок «пароль раньше
      заполненности», признак `locked` в списке.
      Проверка: `npx vitest run apps/server/src/lobbies.test.ts`.
- [x] 1.3 `apps/server/lobby-routes.ts`: пароль телом запроса, отказ
      по паролю кодом 403, негодный пароль — 400.
      Проверка: `npx vitest run apps/server/src/lobby-routes.test.ts`.
- [x] 1.4 Клиент: необязательное поле пароля при создании, замок
      в строке списка, поле пароля прямо в строке при входе, отказ
      остаётся в строке и не стирает введённого.
- [x] 1.5 Сквозная проверка: замок виден до попытки входа, неверный
      пароль оставляет гостя в списке и не занимает места, верный
      пускает.
      Проверка: задача «сквозные проверки» в CI.

## Что этой задачей не делается

Подмена участника при переподключении остаётся возможной: место в
комнате восстанавливается по идентификатору профиля, а профиль
подделывается тривиально. Отказ осознанный, разобран в `proposal.md`;
на доску заводится отдельная задача о настоящей личности игрока.
