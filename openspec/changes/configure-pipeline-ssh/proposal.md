## Why

Рабочий Windows sandbox Codex запускает Node, но не имеет доступа к личному SSH-каталогу владельца. Конвейеру нужен явный путь к отдельной конфигурации SSH для проверки доступа и выкладки.

## What Changes

- Единая переменная `TD_DEPLOY_SSH_CONFIG` для SSH/SCP и проверки готовности.
- Общий помощник удалённых команд для инструкций обоих исполнителей.
- Документация отдельной учётной записи SSH конвейера и проверки перед запуском.

## Capabilities

### New Capabilities

- `pipeline-ssh`: явная конфигурация подключения конвейера с сохранением стандартного поведения без настройки.

### Modified Capabilities

Нет.

## Impact

Сценарии выкладки, проверка готовности Codex, инструкции этапа и документация запуска. На отзывчивость игры и игровой сетевой трафик влияния нет.

## Non-goals

Изменение личных ключей и их ACL, отключение sandbox, изменение проверок производительности или сценария восстановления сервера.
