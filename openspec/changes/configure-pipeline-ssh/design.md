## Context

Windows Codex 0.153.4 с elevated успешно запускает дочерний Node. Личный SSH-каталог недоступен изолированному пользователю. Прежний unelevated даёт EPERM при установке пакетов.

## Goals / Non-Goals

Goals: одинаковая конфигурация SSH на проверке готовности, вспомогательных командах и выкладке обоих провайдеров.

Non-Goals: изменение личных ключей, отключение изоляции, обход perf-проверок. Игровая отзывчивость, трафик, рассинхрон и реконнект не затронуты.

## Decisions

- Необязательный абсолютный путь `TD_DEPLOY_SSH_CONFIG` передаётся через окружение; `ssh` и `scp` получают `-F` отдельным аргументом. Без переменной сохраняются стандартные настройки OpenSSH.
- Общий модуль аргументов используется сценарием deploy и CLI удалённых команд. Проверка Codex вызывает тот же CLI через Node, проверяя реальный выход и маркер.
- Ключ создаётся самим изолированным пользователем в игнорируемом `.pipeline/ssh`. Добавляется только публичная часть в authorized_keys сервера. Отпечаток сервера переносится из уже доверенного known_hosts. Приватный ключ не копируется из личного каталога.
- Локальная настройка окружения включается после успешной пробы. Отключение private desktop не помогло, поэтому не применяется.

## Risks / Trade-offs

- Потеря ключа → пересоздать отдельную пару и удалить только прежнюю строку authorized_keys.
- Неверный путь → отказ до SSH; автоматического отката на личные ключи нет.
- Различия CLI → проверять Git/GH/SSH/Node на том же бинарнике до новых задач.

## Migration Plan

Подготовить отдельный ключ и SSH config, проверить доступ в elevated. После CI и слияния обновить локальный путь CLI и sandbox, задать переменную окружения, проверить startup. Дать старому процессу применить накопленные отчёты в режиме draining и перезапуститься. Проверить реальную выкладку. Для отката убрать переменную и вернуть прежние настройки, оставив паузу при провале startup.
