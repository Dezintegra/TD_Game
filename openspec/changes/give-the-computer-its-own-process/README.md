# give-the-computer-its-own-process

Служба компьютерных дежурных живёт в процессе игрового сервера
(`apps/server/src/main.ts:160`) — в том самом потоке, который считает
тики и рассылает кадры. Любая её заминка задерживает кадры всем идущим
матчам, включая матчи двух людей, к которым компьютер отношения
не имеет.

**Сегодняшняя величина заминки мала, и это сказано в предложении
прямо:** 1,3–3,6 мс на решение при бюджете 33,33. Изменение не про неё.
Оно про то, что величина ничем не ограничена, а последствие её роста
несоразмерно причине. Самый наглядный пример уже в коде: компьютер,
разошедшийся с сервером, синхронно переигрывает весь матч из истории
команд — порядка секунды на пятиминутном матче, — и сегодня эта секунда
останавливает сервер целиком.

**Архитектура к переезду готова.** `packages/bot` ходит только через
сокет и HTTP, от пакета сервера не зависит, и `computer-player` этот
запрет уже закрепляет. Сцепка ровно одна — `computerProfileOf`
(`main.ts:97`), которой лобби спрашивает, компьютерная ли сторона.
Вместо вопроса в чужой процесс делается объявление при старте:
служба предъявляет общий секрет и называет свои личности, сервер
отвечает дальше из своего списка. Обращений за границу процесса
во время матча — ноль.

**Порядок. Делать ПОСЛЕ `measure-the-tick`.** Заявленная польза —
«заминка компьютера перестаёт задерживать рассылку» — проверяется
приборами, и без них останется недоказанной. Разбор, из которого
выросли все три изменения, уже один раз ошибся вдесятеро
на рассуждении без прибора; повторять не стоит.

Задача 5.1 (снять линию «до») выполняется **первой из всех**: после
переезда снять её будет негде.

С `predict-only-for-the-watching` не пересекается: оно трогает
требование «Компьютер получает мир только из потока кадров»
(MODIFIED), а это заводит новые требования и трогает «Отсутствие
компьютера видно, а не молчаливо».

**Заводит одиннадцатое приложение `apps/computer`** — только точку
входа. Дельта на `workspace-structure` — MODIFIED поверх «Фиксированный
состав рабочих пакетов», состав растёт с десяти до одиннадцати.

**Чего изменение не делает.** Не переписывает противника, не квантует
решение (разобрано и отложено в `measure-the-tick/design.md`),
не меняет протокол и правила игры с компьютером, не вводит
масштабирование по машинам и не пересматривает `maxMatches`.

**Честная плата.** Дежурные ходят к серверу через границу процесса,
и задержка ввода компьютера может подрасти на тик — она выводится
из времени кругового обхода. Плата в пользу игрока: сегодня компьютер
живёт к серверу ближе, чем человек.
