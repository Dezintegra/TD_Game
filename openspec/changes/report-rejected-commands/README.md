# report-rejected-commands

Ядро сообщает, почему команда отклонена: отклик игроку и правдивая телеметрия.

Ядро отклоняет негодные команды молча. Игрок из-за этого не получает
отклика на неверное действие, а лог команд не отличает «приказал»
от «приказал, и приказ выбросили». Отказы кладутся в состояние мира
по образцу следов выстрелов и в контрольную сумму не входят.

**Порядок.** Первое из трёх связанных изменений. Не зависит ни от чего;
`add-match-telemetry` зависит от него.


**Состояние:** реализовано, все задачи закрыты, `pnpm verify` зелёный.
