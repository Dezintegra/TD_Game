# Поддержка Claude и Codex

## Why

Проектные навыки и запуск автономных этапов привязаны к Claude. Нужен выбор исполнителя без переноса доски и потери правил проекта.

## What Changes

- Общая точка входа AGENTS.md и шесть проектных OpenSpec-навыков для Codex.
- Выбор провайдера супервизора, по умолчанию Claude.
- Адаптер Codex: запуск, события, продолжение, разрешения и оценка расхода.
- Проверки совместимости и инструкция запуска обоих вариантов.

## Capabilities

### New Capabilities

- `agent-provider`: выбор и изоляция исполнителя этапов.

### Modified Capabilities

Нет.

## Impact

Меняется только инструментарий разработки. Отзывчивость игры и игровой сетевой трафик не меняются.

## Non-goals

Одновременный запуск двух супервизоров на одной станции, перенос истории разговоров между моделями, изменение игры, автоматическая выкладка этой доработки.
