## Одно разрешённое уточнение причины

После отправки `35f3cce` выполнен ровно один вызов:

```powershell
node .matchlog/0299-inspect-resolver.mjs
```

Скрипт вызывает тот же resolver, только чтением, с фиксированным назначением
0083. Код 1. Конкретно отклонена его команда:

```powershell
git -C C:/src/dezintegra/TD_Game/.claude/worktrees/0083-pravka-purpose-speki-ne-dostavlyaetsya-d rev-parse --absolute-git-dir
```

Git сообщил `fatal: detected dubious ownership in repository`: владелец
`.git` дерева отличается от текущего sandbox-пользователя `CodexSandboxOnline`.
Имена владельца и SID в этот документ не копируются. Git предложил изменение
`safe.directory`; оно не выполнялось ни глобально, ни локально, ни через env
или доводы команды. Отказ не обходился другим инструментом/профилем.
Повторных опытов записи и диагностических native-сессий не было.

Sanitizer первого запуска не распознал этот текст, поэтому он записан как
unknown. Одно read-only уточнение установило конкретное препятствие;
неизвестный результат первого вызова не переписан задним числом.
