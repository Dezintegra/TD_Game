## ADDED Requirements

### Requirement: Конвейеру разрешена синтаксическая проверка JavaScript

Настройка разрешений конвейера SHALL покрывать команду `node --check <файл>` в Bash и PowerShell для локальной синтаксической проверки JavaScript в назначенном дереве. Покрытие SHALL определяться общей меркой `supervisor/config/permissions.mjs`: совпадение с allow и отсутствие совпадения с deny. Допуск SHALL ограничиваться приставкой `node --check` и MUST NOT расширяться до общего запуска Node.

Регрессионная проверка SHALL читать действующий файл настройки, проверять обе оболочки и сохранять покрытие уже разрешённых `pnpm install --frozen-lockfile`, `pnpm install --frozen-lockfile --prefer-offline`, `npx eslint <файл>`, `npx prettier --check <файл>` и `npx vitest run --root supervisor <файл теста>`. Проверка настройки MUST NOT объявляться доказательством фактического допуска команд средой текущей сессии.

#### Scenario: Синтаксическая проверка покрыта в обеих оболочках

- **WHEN** общей меркой проверяют `node --check supervisor/config/permissions.mjs` и ту же форму с заключённым в кавычки путём с пробелом
- **THEN** действующая настройка не возвращает непокрытых команд ни для Bash, ни для PowerShell
- **AND** прежние команды подготовки дерева и узких проверок также остаются покрытыми

#### Scenario: Пропавший допуск обнаруживается

- **WHEN** в копии настройки в памяти удаляют допуск `node --check` только для одной оболочки либо заменяют его точной формой без довода файла
- **THEN** проверка обнаруживает непокрытую команду с указанием этой оболочки
- **AND** покрытие второй оболочки не скрывает дефект

#### Scenario: Запрет имеет приоритет

- **WHEN** в копию настройки в памяти добавляют deny для разрешённой команды синтаксической проверки в одной оболочке
- **THEN** общая мерка объявляет команду непокрытой именно в этой оболочке

#### Scenario: Допуск проверки не открывает исполнение сценария

- **WHEN** той же меркой проверяют `node supervisor/config/permissions.mjs`, `node --check-extra supervisor/config/permissions.mjs` и `node --eval "2"`
- **THEN** ни одна из этих команд не получает покрытия в обеих оболочках
- **AND** подмена узкого допуска общим `node:*` в копии настройки обнаруживается регрессионной проверкой
