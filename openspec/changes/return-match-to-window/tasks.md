## 2. Правка

- [x] 2.1 `STRUCTURE_STATS[Base].health`: `BASE_HEALTH * 500` →
      `BASE_HEALTH * 400`. Обоснование рядом с числом переписано.
- [x] 2.2 Эталон детерминизма пересмотрен тем же коммитом:
      `513359514` → `849553914`, история дописана, а не затёрта.
- [x] 2.3 Эталон профилей пересмотрен: `3742757923` → `1992065027`,
      войска девять вместо семи, энергии 1159 вместо 1541. Разбор
      записан рядом: курс перевода урона по базе в энергию выведен
      делением на её запас, поэтому наступление подорожало на четверть,
      и профиль ответил закупкой машин. Остальные четыре величины
      не дрогнули — манеру игры правка не задела.
- [x] 2.4 Проверка «ядерный удар не сносит башню с одного заряда»
      сравнивается с прочностью БАШНИ, а не базы, и не упала.
