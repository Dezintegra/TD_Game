## Context

У 0043 PR #106 влит, у 0128 PR #120 влит, но карточки остаются в review/postmortem. Сохранённые пути отсутствуют. Свежий GitHub и локальная проверка запуска Node подтверждают локальное устаревание состояния. runCycle возвращает план, который bin/supervise печатает как исполнение.

## Goals / Non-Goals

Восстановить продвижение по доказанному состоянию PR и файловой системы и достоверно считать порождения. Не забывать владение ресурсами и не обходить бюджеты, живые сессии, отчёты или инциденты.

## Decisions

- Добавить review в существующую ограниченную сверку PR. Повторное review для игрового diff сохраняет попытки и обязательства, обновляя лишь отметку сверки; служебный merge переводит в cleanup.
- Добавить точный исторический префикс plugins/pipeline/ и тест команд супервизора. Для package.json сравнивать полные документы по закреплённым SHA: допустимы только изменения scripts.supervisor и scripts.supervisor:*. Неполные данные, другие поля или смешанный diff требуют обычной выкладки.
- Реестр остаётся свидетельством владения. Для запуска отдельно проверять физический каталог, верхний уровень Git и ветку. Другой действующий путь той же ветки можно усыновить. Отсутствующее дерево при сохранённой записи восстанавливать только из существующей ветки и после проверки актуального PR; уборке дерево не создавать. Аналитический этап без обязательного дерева получает корень проекта при отсутствии каталога; изменение кода в корне по-прежнему запрещено.
- Считать порождения на границе spawnStage в execute, включая фактически созданный процесс перед неудачной записью карточки. Выводить число процессов, служебных действий и отказов. Продолжение передачи уже созданного процесса не считается новым запуском. Исключение одного действия или починки не прерывает независимые действия; сохранённые глобальные запреты исполняются как прежде.

## Risks / Trade-offs

Утрата незакоммиченных файлов не восстанавливается автоматически; отсутствие ветки не оправдывает создание пустой копии. Сверка GitHub ограничена двумя кандидатами за цикл и короткими тайм-аутами. Проверка каталога повторяется непосредственно перед порождением. Сеть игры, рассинхрон и реконнект не затрагиваются.

## Migration Plan

Установить после ручной приёмки 0244 при остановленном супервизоре. Сохранить снимок состояния, возобновить один экземпляр, проверить продвижение старых карточек и реальные процессы. Откат к предыдущему коду не требует преобразования карточек или удаления реестра.
