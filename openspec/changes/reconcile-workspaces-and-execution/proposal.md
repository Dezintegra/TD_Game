## Why

Карточки 0043 и 0128 возвращаются в review/postmortem после вливания PR и удаления рабочих каталогов. Итог цикла «работа выдана» отражает план, даже если ни один процесс не создан.

## What Changes

- Сверять влитые PR также в review, сохраняя обязательства игровой выкладки.
- Завершать доказанную служебную работу из token-limit через уборку без запуска модели и повышения бюджета.
- Узнавать исторический каталог конвейера и доказанные изменения только команд его запуска в package.json.
- Относить изолированные тестовые инструменты и workflow проверок к служебным изменениям; не освобождать от выпуска изменения сборки игры, зависимостей или смешанный diff.
- Проверять рабочий каталог перед запуском, сохранять сведения для уборки и восстанавливать путь по действующему дереву.
- Отчитываться о фактических процессах отдельно от служебных действий и отказов.

## Impact

Меняются только супервизор, тесты и его спецификация. Отзывчивость интерфейса и игровой сетевой трафик не меняются. Дополнительные чтения GitHub ограничены уже отобранными для сверки PR; локальные проверки каталогов не запускают модель.

## Non-goals

Не повышать бюджеты, не снимать подтверждённые инциденты без проверки и не создавать пустое дерево вместо утраченной незавершённой работы. Ручное завершение 0244 выполняется отдельно по разрешению владельца.
