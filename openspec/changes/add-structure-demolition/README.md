# add-structure-demolition

Генерал может снести свою постройку: выделение объекта, окно сведений
и кнопка сноса.

Поставленное нельзя убрать, и цена этого выше, чем неудобство. Свои
стены непроходимы для своих же юнитов, поэтому перекрывший проход
запирает собственную армию без права на исправление — а замысел
эту тактику прямо разрешает (5.4). Промах мимо клетки под огнём
необратим. И о постройке сейчас нечего узнать: личный рост башни —
заметная механика, но игрок не видит, какая из его башен выросла вдвое.

Снос — команда ядра со своими проверками, требует присутствия генерала
(как и постройка), занимает время (иначе перекрытие стало бы бесплатным
переключателем) и возвращает часть уплаченного.

**Внимание: меняется раскладка байтов** — появляется новая команда,
`PROTOCOL_VERSION` увеличивается.
