## 2. Ход сноса

- [x] 2.1 Снос идёт столько же, сколько возведение того же вида: здоровье
      убывает, клетка остаётся непроходимой, в конце постройка исчезает.
      *Проверка:* тест — на середине сноса клетка ещё непроходима,
      после завершения свободна.
- [x] 2.2 Убедиться, что энергия при сносе не меняется вовсе — ни в его
      начале, ни в конце. В комментарии записать, почему возврата нет:
      он превратил бы стену в барьер напрокат и потребовал бы хранить
      у каждой постройки цену покупки, а с нею лишнее число в контрольной
      сумме и в откате предсказания.
      *Проверка:* тест — энергия игрока до и после полного сноса
      одинакова; повторная постановка стоит полную цену.
- [x] 2.3 Сносимую постройку можно добить.
      *Проверка:* тест — обстрел уничтожает её раньше завершения сноса,
      и мир остаётся согласованным.
- [x] 2.4 Начатый снос не отменяется.
      *Проверка:* повторная команда сноса той же постройки ничего
      не меняет.

## 3. Выделение и окно сведений

- [x] 3.1 Выделение в `ControlState` (`apps/client/src/game/controls.ts`):

      новое поведение занимает пустоту, а не отбирает существующее.
      *Проверка:* с выбранным видом постройки щелчок по-прежнему строит.
- [x] 3.2 `Esc` снимает выделение вместе с режимом размещения.
      *Проверка:* визуально в браузере.
- [x] 3.3 Подсветка выделенной постройки на сцене (PixiJS, не React).
      Цвета — только через переменные из `packages/ui/src/tokens.css`.
      *Проверка:* `pnpm lint` зелёный; выделение видно на поле.
- [x] 3.4 Окно сведений: вид, владелец, здоровье числом и долей, личный
      рост, урон и дальность с учётом прокачки владельца, состояние
      возведения или сноса.
      *Проверка:* выросшая убийствами башня отличима в окне от только что
      построенной.
- [x] 3.5 Сведения о чужих постройках показываются наравне со своими.
      *Проверка:* выделение вражеской башни показывает её характеристики
      с учётом прокачки противника.
- [x] 3.6 Кнопка сноса: только у своих; при невозможности — недоступна
      с указанием причины, а не спрятана.
      *Проверка:* четыре состояния кнопки — доступна, далеко, генерал
      мёртв, это база.
