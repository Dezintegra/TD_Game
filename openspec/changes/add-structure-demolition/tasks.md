# Задачи

## 1. Команда сноса в ядре

- [ ] 1.1 Добавить `CommandKind.Demolish` в `packages/shared/src/commands.ts`:
      игрок, тик, клетка. Клетка, а не идентификатор постройки — по той же
      причине, по которой позиции передаются клеткой.
      *Проверка:* тип экспортируется, сборка зелёная.
- [ ] 1.2 **Увеличить `PROTOCOL_VERSION`** и добавить кодек команды
      в `packages/protocol` по образцу назначения цели.
      *Проверка:* тест кодека — команда кодируется и декодируется без
      потерь; декодер на негодных байтах возвращает ошибку, а не бросает.
- [ ] 1.3 Хранить цену покупки в состоянии постройки, рядом
      с `growthPpm`. В комментарии объяснить: возврат считается от того,
      что уплачено, иначе снос старых стен станет способом зарабатывать
      на собственной прокачке.
      *Проверка:* `pnpm --filter @td/sim typecheck` зелёный.
- [ ] 1.4 Добавить причину отказа «базу снести нельзя» — отдельную
      от «недопустимая цель».
      *Проверка:* тип экспортируется из `@td/shared`.
- [ ] 1.5 Применение команды в `apply.ts`: проверки в порядке из
      `design.md`, начало сноса.
      *Проверка:* тест на каждую причину отказа — чужая постройка, база,
      мёртвый генерал, вне радиуса, пустая клетка, негодный номер клетки.

## 2. Ход сноса

- [ ] 2.1 Снос идёт столько же, сколько возведение того же вида: здоровье
      убывает, клетка остаётся непроходимой, в конце постройка исчезает.
      *Проверка:* тест — на середине сноса клетка ещё непроходима,
      после завершения свободна.
- [ ] 2.2 Возврат энергии в момент завершения, а не в начале.
      *Проверка:* тест — на середине сноса энергия не начислена.
- [ ] 2.3 Сносимую постройку можно добить.
      *Проверка:* тест — обстрел уничтожает её раньше завершения сноса,
      и возврат при этом не начисляется.
- [ ] 2.4 Начатый снос не отменяется.
      *Проверка:* повторная команда сноса той же постройки ничего
      не меняет и не удваивает возврат.

## 3. Выделение и окно сведений

- [ ] 3.1 Выделение в `ControlState` (`apps/client/src/game/controls.ts`):
      левая кнопка без выбранного вида постройки выделяет объект
      под курсором. Сейчас в этом состоянии она не делает ничего —
      новое поведение занимает пустоту, а не отбирает существующее.
      *Проверка:* с выбранным видом постройки щелчок по-прежнему строит.
- [ ] 3.2 `Esc` снимает выделение вместе с режимом размещения.
      *Проверка:* визуально в браузере.
- [ ] 3.3 Подсветка выделенной постройки на сцене (PixiJS, не React).
      Цвета — только через переменные из `packages/ui/src/tokens.css`.
      *Проверка:* `pnpm lint` зелёный; выделение видно на поле.
- [ ] 3.4 Окно сведений: вид, владелец, здоровье числом и долей, личный
      рост, урон и дальность с учётом прокачки владельца, состояние
      возведения или сноса.
      *Проверка:* выросшая убийствами башня отличима в окне от только что
      построенной.
- [ ] 3.5 Сведения о чужих постройках показываются наравне со своими.
      *Проверка:* выделение вражеской башни показывает её характеристики
      с учётом прокачки противника.
- [ ] 3.6 Кнопка сноса: только у своих; при невозможности — недоступна
      с указанием причины, а не спрятана.
      *Проверка:* четыре состояния кнопки — доступна, далеко, генерал
      мёртв, это база.
