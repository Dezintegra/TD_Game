## Why

Повторный implement задачи `0181-ispravit-v-mark-every-command-block-lozh` уже был допущен без доступных документов `mark-every-command-block`. Указание в тексте задачи не заменяет машинное предусловие: нужны закрытие `0175-razmetit-komandnye-bloki-supervisor-skil` и подтверждённое вливание именно PR 132 в main.

## What Changes

- Подготовить адресное дополнение существующей карточки 0181 через `dependencyUpdates` задачи 0242, сохраняя остальные зависимости и метаданные.
- Проверить существующий допуск на конкретных ID и PR 132: сохранение условия, удержание без попыток, отрицательные ответы GitHub и штатное возвращение допуска.
- Зафиксировать свидетельства проверки и последующего независимого подтверждения записи супервизором. Перед реализацией 0181 сохраняется обязательное обновление базы и наличие целевых документов.

## Non-goals

Не разрабатывать механизм 0242 повторно, не менять планировщик и схемы, не писать на доску из сессии, не запускать и не перехватывать 0181, не сбрасывать postmortem/recovery и счётчики, не править документы задачи 0175. Не переносить их из невлитой ветки. Не вводить постоянное требование с номером конкретной карточки.

## Impact

Репозиторный результат — план и свидетельства в собственном каталоге изменения; операционный результат — два дополнения полей карточки силами супервизора. Код игры не меняется, поэтому отклик в том же кадре и игровой сетевой трафик прежние. Служебный трафик — штатная адресная операция Trello и ограниченные чтения GitHub существующего сборщика доказательств, без нового опроса.

Поставка адресного поручения зависит от `append-addressed-card-dependencies` (0242, PR 177) на принимающем супервизоре и остальных активных станциях. На базе 3cccea2 после fetch/merge этого механизма нет. Планирование возможно сейчас; неподдерживаемое поле передавать нельзя. Изменение архивируется ПОСЛЕ `append-addressed-card-dependencies`, с `--skip-specs`; очередность переноса дельт здесь не возникает. `require-merged-pr-for-dependencies` уже доставлено PR 171, но дельта остаётся открытой. Соседние 0246/0247 используют тот же канал для других адресатов, их правки не нужны.

## Почему дельты нет

- `Explicit prerequisite metadata` в `card-dependencies` и его открытая редакция `require-merged-pr-for-dependencies` уже требуют сохранения полных ID и dependencyResults. Конкретное значение 0175/132 не меняет смысл требования.
- `Gate task launches on completion` в той же открытой редакции уже задаёт closed, совпадение links.pr, MERGED, корректную mergedAt, базу main, удержание без попыток и сохранность живых этапов. Мы проверяем эти условия, не расширяя их.
- `Result evidence is read without worker sessions` уже определяет отказ GitHub как отсутствие доказательства и повтор на новом снимке; новая логика не нужна.
- `Completion includes all decomposition descendants` остаётся неизменным: дополнительные зависимости и recovery.fixedBy не подменяются.
- Контракт адресного дополнения из `append-addressed-card-dependencies` применяется без изменения его дельты: объединение, занятость, независимый readback и отсутствие изменения статуса остаются обязанностями 0242.
- Условие свежей базы уже записано в tasks.md `correct-command-block-merge-rationale`; здесь оно является контрольным пунктом передачи, а не новым правилом.

После работы ни основа, ни открытые дельты не читаются иначе. Каталог specs не создаётся.
