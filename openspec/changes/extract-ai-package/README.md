# extract-ai-package

Противник переезжает в `packages/ai` и получает именованные профили поведения.

Противник живёт в клиенте, поэтому его нельзя импортировать в инструмент
на Node — а безголовые прогоны нужны. При этом он уже самодостаточен:
ни одной связи с клиентом, переезд механический. Заодно числа, задающие
манеру игры, собираются в именованный профиль: это даёт сравнение
вариантов и откат настройки без отката кода.

**Порядок.** Второе из трёх связанных изменений. Не зависит ни от чего;
`add-match-telemetry` зависит от него.

**Осторожно: это изменение трогает файлы, которые активно правились.**
Артефакты сверены с `opponent.ts`, `posture.ts` и `approach.ts`
по состоянию на коммит `e9bfe66`. Перед началом работы стоит убедиться,
что модули с тех пор не менялись: `git log --oneline -- packages/ai
apps/client/src/game/ai`. В частности, список величин для профиля
и состав переносимых файлов (их пять, включая `posture.test.ts`)
проверяются глазами по каталогу, а не берутся из этого документа
на веру.

Профиль откатывает **настройку**, а не **устройство**: изменение формул
сравнивается по `git_sha` матчей в аналитической базе.


**Состояние:** реализовано, все задачи закрыты, `pnpm verify` зелёный.
