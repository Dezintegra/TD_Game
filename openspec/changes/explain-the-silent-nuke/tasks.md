# Задачи

Каждый пункт — отдельный коммит, собирающийся и проверяемый сам по себе.
Первый пункт ничего не ломает и ни от чего не зависит: он открывает
черновой pull request, без которого проверки CI на пуши в ветку
не запускаются вовсе.

## 2. Цена шага сетки измерена

- [ ] 2.1 Тест `packages/ai/src/nuke-scan.test.ts`: пустой мир, известное
      скопление штурмовиков, центр которого приходится на середину между
      четырьмя узлами сетки с шагом `BASELINE_PROFILE.nuke.scanStep`.
      Сравнить чистую ценность лучшего узла сетки с чистой ценностью
      в самом центре скопления и напечатать отношение.

      Тест обязан **падать**, если две оценки совпали: совпадение
      означает, что скопление поставлено не туда и измерять нечего.
      Порога на само отношение не задавать — величина диагностическая.

      **Проверка:** `npx vitest run packages/ai/src/nuke-scan.test.ts` —
      зелено, в выводе есть отношение. Сдвиг скопления в узел сетки
      роняет тест.

## Чего в этом списке нет

**Самого замера.** Прогон арены на паре `baseline-2026-08` против
`strategist-2026-08` — шестьдесят матчей, зерно 3000, тот же состав,
что у прогона 33105088891, — заказан отдельной задачей типа `run`
и здесь пунктом не стои́т.

Не по забывчивости, а намеренно: пункт списка, который этап не вправе
исполнить, никогда не будет отмечен, и работа, сделанная целиком,
навсегда останется незавершённой на бумаге. Очередь прогонов ведёт
бэклог, и связь с этой задачей держится ссылкой, а не галочкой.
