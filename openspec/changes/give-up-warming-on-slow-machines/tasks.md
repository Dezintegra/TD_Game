# Задачи

Каждая — отдельный коммит, отправляемый сразу. Порядок выбран так, чтобы
любая остановка оставляла работоспособное состояние.

## 1. Прогрев отчитывается о сделанном

- [x] 1.1 `scene.ts`: `RendererHost.warm(budgetMs)` возвращает
      `{ baked, rest }` вместо `boolean`. `session.ts` читает `rest > 0`
      там, где читал `true`. Поведение не меняется ничем.

## 2. Мерка скорости прогрева

- [x] 2.1 Завести `apps/client/src/session/warm-pace.ts`: копит замеры
      «время на одно запекание», выбрасывает первый шаг, отвечает
      на вопрос «укладывается ли остаток в срок». Константы
      с обоснованием: `WARM_HORIZON_MS = 6_000`, `WARM_SAMPLE_MIN = 4`.
- [x] 2.2 Модульные тесты `warm-pace.test.ts`: здоровая скорость проходит,
      медленная останавливает, компиляция шейдера не судит машину,
      приговор не выносится раньше четырёх замеров.

## 3. Прогрев отступает

      сказав об этом в консоль с цифрами. `rewarmInMenu` отступ уважает.
