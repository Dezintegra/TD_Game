## Context

Готовность Git и SSH не доказывает способность Node запустить pnpm lifecycle,
сборку или Playwright. EPERM воспроизведён отдельным скриптом без установки пакетов.

## Goals / Non-Goals

Выявить неисправную среду до выдачи задач. Не менять политику песочницы автоматически.

## Decisions

Временный каталог существующей стартовой пробы получает небольшой .mjs.
Он запускает дочерний Node с фиксированным маркером и на Windows cmd с echo.
Тайм-аут каждого дочернего процесса 10 секунд; окружение и секреты не печатаются.
Исполнитель вызывает скрипт отдельной пятой командой. Приёмка требует exit0,
завершённый command_execution с именем скрипта и точный итоговый маркер.
Текст модели и echo маркера без запуска скрипта не принимаются.
Файл удаляется вместе с пустым временным каталогом в finally.

## Risks / Trade-offs

Дополнительная команда удлиняет стартовую пробу → сохраняем общий лимит 120 секунд.
Ложное обещание модели → проверяем событие инструмента и реальный вывод.

## Migration Plan

Обновить супервизор после обработки ожидающих отчётов. Ошибка пробы оставляет
конвейер на паузе без запуска карточек. Изменение private desktop требует
отдельного согласия владельца и не входит в автоматическую реакцию.
