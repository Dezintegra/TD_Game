## Why

Deploy0222 прошёл Git, GitHub и SSH, затем остановился на pnpm install:
Node внутри песочницы не может порождать дочерние процессы (EPERM).
Такую среду нужно распознавать до захвата задач.

## What Changes

Стартовая проба Codex проверяет дочерний Node и системную оболочку Windows.
Без фактически успешной команды и ожидаемого вывода задачи не выдаются.

CI обычных браузерных проверок запускается одним worker и сохраняет трассу
падения: два прогона текущего PR с двумя workers воспроизвели тайм-аут клика,
а второй также не дождался общего тика. Проверки и их сроки не ослабляются.

## Capabilities

### New Capabilities

- `codex-process-readiness`: проверка дочерних процессов до выдачи задач.

### Modified Capabilities

Нет. Дополняет проверки окружения из check-codex-deploy-readiness и use-native-git-auth.

### Почему дельты CI нет

Требования к игре и полный набор CI сохраняются; меняется только распределение
ресурсов прогона и сбор диагностики. Это настройка выполнения существующих проверок.

## Impact

Стартовая проверка супервизора, её тесты и документация запуска.
Отзывчивость интерфейса и игровой сетевой трафик не меняются.

## Non-goals

Автоматическое ослабление песочницы, обход EPERM, установка зависимостей
вне исполнителя, изменение моделей и пропуск замера.
