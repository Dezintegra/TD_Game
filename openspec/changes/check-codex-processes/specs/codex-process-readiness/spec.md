## ADDED Requirements

### Requirement: Дочерние процессы доступны до выдачи задач

Стартовая проверка Codex MUST подтверждать успешный запуск дочернего Node
и системной оболочки на Windows. Неуспех MUST запрещать выдачу задач.

#### Scenario: EPERM при запуске дочернего процесса

- **WHEN** Node получает EPERM, хотя Git и SSH доступны
- **THEN** стартовая проба завершается неуспешно и конвейер остаётся на паузе

#### Scenario: Успешный запуск

- **WHEN** проверочный скрипт выполняется с кодом 0 и точным маркером
- **THEN** проверка процессов считается пройденной вместе с остальными проверками среды

#### Scenario: Обещание вместо проверки

- **WHEN** маркер находится только в тексте модели или выводе echo
- **THEN** готовность не подтверждается
