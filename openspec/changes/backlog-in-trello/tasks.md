## 2. Разбор и сборка карточки

Всё в этом разделе — чистые функции без сети. Они и покрываются тестами.

- [x] 2.1 Написать разбор карточки в задачу: идентификатор и машинные поля
      из блока, состояние из колонки, тип и вид прогона из меток, приоритет
      из положения, ожидаемый результат из раздела описания. Проверяемо:
      тест на карточке каждого типа задачи. **Отметка заведения нигде
      не хранится: первые восемь знаков идентификатора Trello — это время
      создания карточки, и подделать его правкой описания нельзя**
- [x] 2.2 Написать сборку задачи в карточку: машинный блок дописывается
      в конец описания, человеческий текст выше блока не трогается.
      Проверяемо: тест правит блок в описании с текстом человека и сверяет,
      что текст цел
- [x] 2.3 Написать проверку карточки взамен схемы: ровно одна метка типа,
      для `run` — метка вида прогона и непустой ожидаемый результат.
      Проверяемо: тест на карточке без ожидания, на карточке с двумя метками
      типа и на годной карточке. **Заодно снятие метки «не разобрано»:
      она уходит сама, как только карточку исправили, — требовать от
      человека ещё и снять её значило бы оставлять на доске красноту,
      которую никто не уберёт**
- [x] 2.4 Написать разбиение журнальной записи на комментарии по пределу
      в 16384 знака с нумерацией частей. Проверяемо: тест на записи в один
      комментарий, в три и ровно в предел; ни одна строка не теряется.
      **Разрыв идёт по строкам: разрезанная посередине строка лога нечитаема.
      Строка, сама не помещающаяся в предел, режется по знакам — иначе её
      было бы вовсе не опубликовать**
- [ ] 2.5 Написать отличение своих комментариев от человеческих по пометке
      и поиск ответа владельца продукта — первого комментария без пометки
      после вопроса. Проверяемо: тест, где после вопроса идут два
      комментария конвейера и один человеческий
