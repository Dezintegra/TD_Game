## 1. Уточнить комментарий о событии error

- [ ] 1.1 Одним атомарным коммитом (до 1 часа) переписать только комментарий непосредственно перед `child.on('error')` в `supervisor/lib/run-stage.mjs`: событие само по себе не означает несостоявшийся запуск; отсутствие `pid` супервизор отдельно обрабатывает как `not-born`, а ошибка уже родившегося процесса относится к обрыву сессии. Убрать безусловное противопоставление лечения продолжением и настройкой. Сохранить все исполняемые строки, обработчики, диагностику, порядок условий, счётчики и соседние комментарии. Выполнить проверки ниже и отметить этот пункт в собственном `tasks.md` тем же коммитом. После отправки первого коммита реализация готова к открытию чернового PR по правилам implement.

Проверки и состав шага; `.` в командах означает назначенное рабочее дерево. Каждая команда выполняется отдельным вызовом:

- Просмотреть `git -C . diff -- supervisor/lib/run-stage.mjs` и сверить новый текст с проверкой `!handle?.pid` и возвратом `not-born` в `supervisor/lib/supervisor.mjs`. Наблюдаемый результат: изменён только указанный комментарий, названы обе стороны границы, утверждения о безусловном способе лечения нет; ни одна исполняемая строка и ни одна строка диагностики не изменена.
- Добавить явный перечень своих путей: `git -C . add -- supervisor/lib/run-stage.mjs openspec/changes/clarify-process-error-comment/tasks.md`. В первом допустим только указанный комментарий, во втором — отметка выполнения этого пункта; прочие изменения даже внутри этих файлов недопустимы.
- Перед коммитом выполнить `git -C . diff --cached --check`, проверить имена через `git -C . diff --cached --name-only` и весь текст через `git -C . diff --cached`. Ожидаются только рабочая правка комментария и собственная отметка выполнения.
- После коммита проверить имена через `git -C . show --format= --name-only HEAD` и содержание через `git -C . show --format= HEAD` по тем же ограничениям; отправить коммит сразу.

Формы Git покрыты `PowerShell(git -C:*)` в `supervisor/config/stage-settings.json`. Тесты, сборка и замеры для этой правки комментария не требуются. Ожидание CI в шаг не входит: проверки и переходы обрабатывает супервизор. Дельты и чужие артефакты не редактируются.
