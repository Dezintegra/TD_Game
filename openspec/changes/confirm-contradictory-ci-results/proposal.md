## Why

Штатный опрос PR 219 застревает на проверке «затронутые области»: GitHub одновременно возвращает `IN_PROGRESS`, `SUCCESS` и время завершения. На свежей базе `7a12154` подтверждено, что workflow 34276070514 завершён успешно на текущем head `3ebe398ce704e377e5b6a16f4e30d3eef3f2553c`, попытка 1; противоречие присутствует также в REST-ответе задания 102229264668. Без сверки результата workflow задача 0052 не достигает review.

## What Changes

- Добавить в штатный `readExternal(task, 'ci')` адресное подтверждение противоречивых GitHub Actions checks через связанный workflow, его актуальную попытку и полный набор заданий.
- Разрешать только подтверждённое противоречие; сохранить запрет успеха при работающем CI, другом SHA, новой попытке, ошибке, отмене, неполном или недоступном ответе и конфликте PR.
- Сохранить фактический пример PR 219 и покрыть весь путь опроса регрессией и отрицательными контролями.
- Зафиксировать однократную приёмку исправленного опроса PR 219 отдельным проверяемым артефактом.

## Non-goals

Не перезапускать CI, не менять workflow, branch protection, доску или PR 219. Не вводить новый маршрут состояний, таймер ручного ожидания, постоянный кеш успеха или исключение для номера PR/имени задания. Не расширять допустимые результаты CI за пределы существующих SUCCESS/SKIPPED. Не менять игру и правила запуска этапов.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `pipeline-ci-observation`: подтверждение завершения противоречивых проверок с сохранением контроля слияния, актуальности и полноты CI. Добавляется отдельное требование; существующее требование о неопределённости уточняется с сохранением всех сценариев.

## Impact

Код: `supervisor/lib/io.mjs`, новый узкий модуль подтверждения CI и тесты переходника; артефакт приёмки в каталоге этого изменения. Контракт `state: pending|failure|success|conflict` сохраняется, `applyExternal` продолжает штатный переход. Новых зависимостей пакетов нет.

Отзывчивость интерфейса игры и её сетевой трафик не меняются: исправление исполняется только в процессе супервизора. Трафик GitHub увеличивается лишь при обнаруженном противоречии: чтение метаданных, полных страниц заданий и повторная сверка актуальности. Запросы ограничены одним опросом и бюджетом; исчерпание бюджета сохраняет pending.

## Dependencies and crossings

Основа `pipeline-ci-observation` уже в `openspec/specs/` после `detect-ci-conflicts`; зависимости архивации нет. Список открытых изменений проверен после fetch/merge origin/main. `keep-ci-waiting-out-of-tasks` описывает автоматический опрос, `supervise-the-pipeline` и `undraft-before-merge` — общий маршрут и запрет ревью до успешного CI: их правила сохраняются, файлы не меняются. Задача 0052 и её `forbid-uncovered-benchmark-probes` являются потребителем исправления, не предпосылкой. Ветка/PR/артефакты 0052 не заимствуются.
