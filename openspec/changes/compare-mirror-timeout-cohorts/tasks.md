## 4. Команды и состав каждого коммита

Это общие условия исполнения пунктов выше, не отдельные задачи и не ожидание CI. Каждый пункт — свой коммит и немедленная отправка. В каждом коммите отметить выполненный пункт только в `openspec/changes/compare-mirror-timeout-cohorts/tasks.md`.

Для чтения исходных данных использовать команды по одной, из назначенного дерева:

```powershell
gh run view 33430184681 --json headSha,conclusion
gh api repos/Dezintegra/TD_Game/actions/runs/33430184681/artifacts
gh run download 33430184681 --name arena-33430184681 --dir .matchlog/0050-source
gh api repos/Dezintegra/TD_Game/actions/jobs/99613388157/logs --allow-escape-sequences
```

Путь SQLite внутри скачанного артефакта определить через `rg --files .matchlog/0050-source --hidden --no-ignore`. Читать исходную базу, не запускать ingest или replay. Если артефакт уже недоступен, оформить обязательную предпосылку восстановления именно исходных данных по действующему контракту blocked; новый прогон иной ревизии не является заменой. Сохранить и отправить завершённую часть до отчёта.

Прямой запуск нового файла в scripts пока не перечислен в разрешениях этапа. Для применения готового модуля использовать разрешённый временный `.matchlog/0050-analyze.mjs`: он импортирует экспортированную функцию CLI из `scripts/analysis/mirror-timeouts.mjs` и передаёт ей параметры из argv; игровой код не импортирует и матчи не запускает. Та же форма позволяет выполнить независимые SQL-проверки и посчитать хеш файла. Исполнение:

```powershell
node .matchlog/0050-analyze.mjs --db .matchlog/0050-source/arena.sqlite --run 33430184681 --sha 69bf0809e7ed2e3aa4be5a1e5f9265b1823aaacf --profile baseline-2026-08 --seed-start 1 --matches 60 --ticks-per-second 30 --cap-seconds 1200
```

Имя SQLite в примере заменить обнаруженным путём, если упаковка отличается. Все локальные производные результаты остаются в `.matchlog/0050-source/`; в исторический отчёт включаются проверенные таблицы и воспроизводимая команда, а не вся база.

Разрешённые пути добавления задаются явным списком для своего шага:

- 1.1 и 1.2: `scripts/analysis/mirror-timeouts.mjs`, `scripts/analysis/mirror-timeouts.test.mjs`, собственный `openspec/changes/compare-mirror-timeout-cohorts/tasks.md`.
- 2.1: те же три пути и `apps/arena/README.md`.
- 3.1: `docs/analysis/mirror-timeouts-33430184681.md` и собственный `openspec/changes/compare-mirror-timeout-cohorts/tasks.md`.

До коммита сверить имена и содержание `git -C <дерево> diff --cached --name-only` и `git -C <дерево> diff --cached`; после создания — `git -C <дерево> show --stat --oneline HEAD` и `git -C <дерево> show --format=fuller HEAD`. Допуск пути не разрешает посторонние изменения внутри файла, включая tasks.md. `.matchlog/0050-source/` и `.matchlog/0050-analyze.mjs` должны отсутствовать в индексе и созданном коммите. Чужие файлы не добавлять, `git add -A` не использовать.

Git-команды всегда давать формой `git -C <дерево> ...`; после каждого коммита — `git -C <дерево> push -u origin HEAD`. Проверка отсутствия хвоста: `git -C <дерево> log --oneline '@{u}..HEAD'`. Полный verify, матчевые тесты, сборка и ожидание CI не входят в этот список; CI наблюдает супервизор.
