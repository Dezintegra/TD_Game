# Задачи

Каждый пункт — отдельный коммит, отправляемый сразу.

Порядок выбран так, чтобы **правило переключалось ровно одним коммитом
(6.1), а все предыдущие оставляли поведение конвейера прежним.** Разбор,
улики и запись в журнал заводятся раньше, но до 6.1 поле `denials`
в отчёте всегда пусто, вердикт всегда «отказов нет», и ни одна задача
не меняет своей судьбы. Обратный порядок дал бы промежуточный коммит,
в котором отбраковка уже снята, а замена ещё не подключена, — то есть
принимающий любой отчёт.

Тесты конвейера обычным `vitest` не видны, у них свой корень:
`npx vitest run --root plugins/pipeline <файл>`.

## 1. Чистый разбор отказов

- [x] 1.1 Завести `plugins/pipeline/lib/denials.mjs` с функцией
      `judgeDenials({ denials, report, stage, evidence })`, возвращающей
      `{ verdict, why }`, где `verdict` — `passing`, `undermining` либо
      `unverifiable`. Улики приходят доводом, git и файлов модуль
      не касается. Таблица следов из замысла живёт здесь данными,
      а не ветвлениями. Проверяемо: `denials.test.mjs` —
      пустой перечень даёт `passing`; обращение к человеку даёт
      `undermining` при любом следе и любом исходе; исходы `question`,
      `rejected`, `failed` дают `passing`; `design` без ветки у origin
      даёт `undermining`; `implement` с хвостом даёт `undermining`;
      `audit` без свежего коммита, но и без хвоста даёт `passing`;
      `benchmark` с тем же номером прогона даёт `undermining`;
      `interpret` и `deploy` дают `unverifiable`; отсутствующая улика
      даёт `unverifiable`, а не `undermining`

  Открыть черновой pull request сразу после этого коммита: до открытия
  PR проверки CI на пуши в ветку не запускаются вовсе.

## 5. Вердикт применяется

- [ ] 5.1 Провести вердикт через `execute.transferReport`: улики
      спрашиваются только при непустом `report.denials`;

      в обоих случаях. Проверяемо: `execute.test.mjs` — попутный отказ
      двигает задачу по маршруту и виден в журнале; подрывающий отправляет

      отчёта есть в записи журнала; при пустом перечне отказов улики
