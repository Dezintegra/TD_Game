# Задачи

Каждый пункт — отдельный коммит, отправляемый сразу.

Порядок выбран так, чтобы **правило переключалось ровно одним коммитом
(6.1), а все предыдущие оставляли поведение конвейера прежним.** Разбор,
улики и запись в журнал заводятся раньше, но до 6.1 поле `denials`
в отчёте всегда пусто, вердикт всегда «отказов нет», и ни одна задача
не меняет своей судьбы. Обратный порядок дал бы промежуточный коммит,
в котором отбраковка уже снята, а замена ещё не подключена, — то есть
принимающий любой отчёт.

Тесты конвейера обычным `vitest` не видны, у них свой корень:
`npx vitest run --root plugins/pipeline <файл>`.

Тесты конвейера обычным `vitest` по-прежнему не видны, у них свой корень:
`pnpm test:pipeline` либо `npx vitest run --root supervisor <файл>`.

до появления улики ветка «либо новый pull request» не может дать ничего,
кроме «следа нет», и обратный порядок оставил бы промежуточный коммит,
в котором имплементация без коммита отбраковывается строже прежнего.
