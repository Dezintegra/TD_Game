## 1. Поставить пробу и записать ответ в скилл проработки

- [ ] Завести пустышку в своём рабочем дереве:
      `openspec new change probe-archive-sandbox --description "Пустышка
      для пробы архивации бездельтового изменения"`. Убедиться, что
      каталога `specs/` у неё нет (состав каталога — поиском файлов).
- [ ] Основная проба:
      `openspec archive probe-archive-sandbox --skip-specs --yes`.
      Записать команду, код возврата и вывод.
- [ ] Если основная проба отвергнута встроенной проверкой — вторая проба
      той же пустышкой (или заново заведённой, если первая уже уехала):
      `openspec archive probe-archive-sandbox --skip-specs --no-validate --yes`.
      Ключ `--yes` обязателен: без него `--no-validate` спросит
      подтверждения, а неотвеченное подтверждение в автономном запуске
      оборачивается отказом, и проба покажет поведение оболочки вместо
      поведения инструмента.
- [ ] В `supervisor/skills/design.md`, в запрете «Архивировать изменение»,
      заменить абзац «**Проба этой команды на изменении без дельт ещё
      не ставилась**…» на ответ пробы. В ответе назвать: исход, версию
      OpenSpec (`openspec --version`), дату пробы и — если понадобился
      `--no-validate` — прямое следствие, что путь открыт человеку
      с живой консолью и закрыт автономной сессии конвейера.
- [ ] Пустышку и её архивированную копию **в коммит не включать**:
      `git add -- supervisor/skills/design.md` и ничего сверх. Убрать
      их сессия не может — удаление файлов оболочкой правилами
      не открывается, — но неотслеживаемый файл уйдёт вместе с деревом.
- [ ] Протокол пробы (команда, код возврата, ключевые строки вывода)
      положить в тело коммита повторными `-m`, по абзацу на `-m`.

  **Проверка:** `git status --porcelain` показывает архивированную
  пустышку строками `??` и ни одной строкой в индексе, кроме
  `supervisor/skills/design.md`; в коммите ровно один файл
  (`git show --stat HEAD`); слов «проба… не ставилась» в скилле
  не осталось.

  **После этого коммита открыть черновой pull request** — до него
  отправки в ветку не запускают ни одной проверки CI.
