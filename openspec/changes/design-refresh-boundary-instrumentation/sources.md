## Статус доказательства

- Подтверждено: источники и технические точки расширения существуют; схема штатного лога недостаточна; разные lifetimes/singleflight требуют явных связей.
- Спроектировано: диагностический envelope, transport, schema, token/API observation, provenance admission, отрицательные контроли и лимиты.
- Не подтверждено: инструментированная сборка, её происхождение по build receipt, выбранный в опыте helper, доступ TOKEN_QUERY, успешная доставка, полнота реального bundle, причина исторического отказа и ремонт.

Ошибки разведки: первоначальный путь upstream `src/bin/setup_main.rs` дал HTTP 404; tree API указал `src/bin/setup_main/win.rs`, прочитан успешно. Первоначальная ссылка Microsoft с `accctrl` недоступна; правильная `aclapi` прочитана. `rg` по двум предполагаемым локальным каталогам изменений сообщил об отсутствии; действующая норма прочитана в основной `pipeline-supervision-resilience`. Это ошибки выбора адреса, не обход ограничений. Git предупредил о недоступном глобальном ignore; успешные команды не обходили этот отказ чтения.
