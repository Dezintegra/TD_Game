В индекс добавлять явным перечнем только тринадцать рабочих путей пункта 1.1 и `openspec/changes/guard-declared-purpose-updates/tasks.md` с отметкой выполнения. При необходимости делить `git -C <дерево> add -- <пути>` на несколько коротких вызовов. До коммита сверить `git -C <дерево> diff --cached --name-only` и `git -C <дерево> diff --cached`, после — `git -C <дерево> show --stat HEAD` и `git -C <дерево> show --format=fuller HEAD`: допустимы только механизм, его проверки, необходимые инструкции и собственная отметка. Чужие изменения внутри разрешённых файлов также исключены.

Fixtures создаются тестами в собственном подкаталоге `.matchlog/` внутри дерева и удаляются ими; ни временный проект, ни его архивная копия не попадают в индекс/коммит. Реальное изменение и основные спецификации этой карточкой не архивируются и не редактируются. Тест использует подставной CLI, поэтому проба `probe-archive-sandbox` не создаётся. Проверить отсутствие изменений `.matchlog/` в индексе и коммите явными `git -C <дерево> diff --cached -- .matchlog/` и `git -C <дерево> show HEAD -- .matchlog/`.

Проверки OpenSpec по имени: `openspec validate guard-declared-purpose-updates --strict` и `openspec status --change guard-declared-purpose-updates`. Полные тесты, сборка, арена и замеры локально не запускаются. Механизм и его подключение поставляются вместе, чтобы промежуточный коммит не обещал ещё отсутствующую защиту.
