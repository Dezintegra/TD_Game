## Context

Все задания CI запускаются безусловно. Быстрый набор смешивает служебные и игровые тесты; матчевый набор доминирует по времени ожидания.

## Goals / Non-Goals

Цель — не запускать игру для правок служебных областей. Выбор отдельных пакетов и тестов внутри игры не входит в изменение.

## Decisions

- Разрешать пропуск только для известных служебных каталогов `supervisor/`, `manage/`, `docs/`, `openspec/`, `.agents/`, `.claude/` и корневых Markdown-файлов. Сценарии `scripts/` консервативно включают игру: среди них есть баланс и сборка. Неизвестные пути, общие конфиги и зависимости также включают игру. Список исключений безопаснее списка игровых путей: новые пакеты не окажутся вне проверок.
- Отдельное задание читает полный Git diff без лимитов API. Для PR сравнивается merge-base базы и головы с головой; для push — before и after. `--no-renames` учитывает обе стороны переноса, `-z` сохраняет имена с пробелами и переводами строк. При ошибке или неподдерживаемом событии выбирается полный прогон.
- Формат, линт, тесты scripts и supervisor остаются обязательными, поскольку служебные тесты читают документы и игровые константы. В задании быстрых тестов условным становится только `turbo run test`.
- Условие применяется к заданиям типов, матчей, сборки и e2e, а не к workflow целиком: обязательные проверки сохраняют имена и получают skipped. Ошибка задания определения изменений включает игровые проверки через `always()` и проверку результата; отмена не запускает новые задания.
- Определитель печатает решение и причину в журнал и summary GitHub. Внешних Actions и зависимостей не добавляется.
- Супервизор принимает завершённые проверки со статусом SKIPPED как штатный пропуск, согласованно с GitHub. FAILURE и CANCELLED остаются ошибками; набор целиком из пропусков без единого SUCCESS не считается проверенным.

## Risks / Trade-offs

Изменение только интерфейса всё ещё запускает матчевые тесты — сознательный запас безопасности на первом этапе. Изменение CI также запускает полный набор и проверяет сам механизм. Откат — вернуть безусловные задания и команду `pnpm test`.

## Migration Plan

Добавить определитель с узкими тестами и условия workflow одним атомарным изменением. Проверить сценарий PR №155, игровой файл, конфигурацию, удаление, перенос и недоступную базу; дождаться CI своего PR. Уже идущие прогоны чужих PR не отменяются.
