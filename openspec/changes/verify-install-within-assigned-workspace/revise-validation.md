# Проверка замечания о маркере кеша — 06.09.2026

`.pnpm-store/v10/index/` и связанных файлов в `v10/files/`.
Для одного полного пакета проверяются размеры и SHA-512 всех файлов,
включая исполняемые файлы с суффиксом `-exec`; имя и версия в сохранённом

отвергаются. Формат сверен с установленным pnpm 10.12.4:
`STORE_VERSION`, `getIndexFilePathInCafs`, `getFilePathByModeInCafs`.

когда установщик вернул код 0 и оставил только непустой `marker.txt`.
