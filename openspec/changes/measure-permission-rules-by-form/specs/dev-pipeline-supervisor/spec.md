## ADDED Requirements

### Requirement: Сторож покрытия мерит правило разрешений по его форме

Сторож покрытия команд вливания SHALL различать две формы правила
разрешений и мерить каждую так, как её мерит среда:

- правило с хвостом `:*` (`Bash(gh pr:*)`) — **приставка**: команда
  покрыта, если начинается с тела правила и продолжается доводами либо
  кончается на его границе;
- правило без хвоста `:*` (`Bash(gh pr view)`) — **точное совпадение**:
  команда покрыта, только если совпадает с телом правила целиком.

Сторож MUST NOT применять приставочную мерку к правилу, записанному без
хвоста `:*`. Именно это он делает сегодня, отбрасывая хвост безусловно,
и потому молчит на настройке, где среда откажет каждой команде вливания.

Одна и та же мерка SHALL применяться к правилам из `allow` и из `deny`:
команда покрыта, только если совпала хотя бы с одним правилом `allow`
и не совпала ни с одним правилом `deny`.

Толкование звёздочки **внутри** тела правила (`git -C * push`) остаётся
прежним — она стоит вместо довода; настоящее требование говорит только
о хвосте.

#### Scenario: Широкое правило сужено до точных форм

- **WHEN** правила `gh pr:*` заменены на точные `gh pr view`,
  `gh pr ready` и `gh pr merge` без хвоста `:*`
- **THEN** сторож числит непокрытой каждую из трёх команд вливания
  в обеих оболочках, поскольку все они идут с доводами

#### Scenario: Приставочное правило покрывает команду с доводами

- **WHEN** в `allow` стоят `Bash(gh pr:*)` и `PowerShell(gh pr:*)`,
  а запретов на `gh pr` нет
- **THEN** сторож не числит непокрытой ни одну команду вливания

#### Scenario: Запрет точной формы, дословно равный команде

- **WHEN** в `deny` стоит правило без хвоста `:*`, тело которого дословно
  совпадает с командой вливания
- **THEN** сторож числит эту команду непокрытой, несмотря на стоящее
  разрешение

#### Scenario: Запрет точной формы, короче команды

- **WHEN** в `deny` стоит правило без хвоста `:*`, тело которого лишь
  начинает команду вливания, но не равно ей
- **THEN** сторож не числит команду непокрытой по этому запрету:
  среда такой запрет к команде с доводами не применяет
