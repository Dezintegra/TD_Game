---
name: openspec-update-change
description: Обновить существующие плановые артефакты OpenSpec и устранить противоречия между ними без реализации кода.
---

Прочитайте AGENTS.md. Выберите изменение из поручения; при неоднозначности
получите `openspec list --json` и уточните. Получите
`openspec status --change <имя> --json` и прочитайте существующие артефакты.
Используйте existingOutputPaths, если CLI их сообщает: не пишите файл по glob.

Внесите порученную правку и проверьте согласованность остальных артефактов
во всех направлениях. Для существенной переработки получите шаблон через
`openspec instructions <artifact-id> --change <имя> --json`.
Объясните предлагаемую смену замысла и согласуйте её; уже разрешённое
редактирование не требует повторного подтверждения каждого файла.

Обновляйте только существующие плановые артефакты. Отсутствующие артефакты
назовите отдельно; этот навык не продвигает создание плана и не меняет код.
Если план уже реализован, укажите необходимую доработку реализации.
Сохраните правило изменений без дельты, когда требования не меняются.
